개인정보처리방침

마켓코파일럿(Market Copilot)은 서비스를 제공하는 데 필요한 정보만 처리하며, 이용자가 자신의 기록을 확인하고 삭제를 요청할 수 있도록 아래 기준을 적용합니다.

시행일: 2026년 11월 25일 · 버전 1.1 · 적용 대상: 공개 웹사이트와 회원 서버를 이용하는 무료 베타

핵심 내용
  • 운영 명칭은 마켓코파일럿이며, 개인정보 문의는 운영자가 직접 담당하는 고객지원에서 처리합니다.
  • 회원 기록은 회원 탈퇴 또는 해당 기록의 삭제 요청을 처리할 때까지, 일반 문의는 처리 종료 후 최대 90일간 보관합니다.
  • 현재 결제를 받지 않으며 실제 광고·Google Analytics·외부 생성형 AI를 실행하지 않습니다.
  • 비회원 기록은 브라우저에 남습니다. 브라우저 데이터를 지우는 것과 서버 회원 기록을 지우는 것은 별개입니다.

2. 처리하는 정보와 목적

기본 마켓·분석·뉴스·가이드는 가입 없이 이용할 수 있습니다. 회원 저장과 연결 기능은 이용자가 선택한 범위에서 처리합니다. 회원 관리·요청한 기록 저장은 서비스 제공을 위한 계약의 체결·이행, 부정 접근 방지는 필요한 범위의 정당한 이익을 근거로 합니다. 별도 동의가 필요한 기능은 사용 전에 그 목적과 항목을 안내받고 선택할 수 있도록 합니다.

계정 생성·로그인·복구
아이디, 비밀번호·복구 코드의 단방향 검증값, 내부 회원 식별자, 가입 시각, 로그인 세션 검증값·만료 시각을 처리합니다. 비밀번호와 복구 코드 원문은 저장하지 않습니다. 계정을 구분하고 접근을 확인하기 위한 정보입니다.
이용자가 저장한 회원 기록
관심종목·메모·검토 이력, 보유·거래 기록, 가격 계획·시나리오, 연구실·ETF 수급 기록 등 선택한 기능의 입력·저장 자료입니다. 기록을 보관하고 기기 사이에 동기화하는 데 사용합니다. 입력한 매매 기록을 거래소가 확인한 실제 체결로 간주하지 않습니다.
가격·조건 관찰
종목·거래소·통화, 등록 조건, 관찰 시각·가격·결과와 알림 처리 상태를 저장합니다. 이용자가 등록한 조건을 확인하고 이후 결과를 보여주는 데 사용합니다.
선택한 거래소 연결
Hyperliquid 지갑 주소·Lighter 계정 식별자 또는 Binance·Bybit 조회용 API 키와 비밀 키, 연결 이름·관찰 기준, 조회한 포지션과 위험 관찰 결과를 처리합니다. API 키는 서버의 암호화 보관함에 저장합니다. 조회 요청은 해당 거래소의 인증 방식에 따라 전송하며 자동 주문에 사용하지 않습니다.
이메일 인증·Telegram 연결
기능을 제공하고 이용자가 선택한 경우 이메일·인증 시각·한시적 인증 기록, Telegram 대화방 식별자·연결 시각·선택한 알림 내용을 처리합니다. 현재 공개 서버의 인증메일과 Telegram 발송은 활성화되지 않았습니다. 활성화 전에 제공업체와 선택 절차를 안내합니다.
고객 문의
보낸 사람의 이메일 주소, 문의 내용, 자발적으로 첨부한 오류 자료 및 응답 기록을 문의 해결과 후속 확인에 사용합니다. 비밀번호·복구 코드·거래소 비밀 키·주민등록번호를 보내지 마세요.
접속·보안 정보
페이지·API 요청 과정에서 IP 주소, 접속 시각, 요청 경로, 브라우저 정보와 오류·응답 상태가 호스팅 사업자에게 전달될 수 있습니다. 서비스 전달, 장애 확인, 남용 방지에 사용합니다. 앱의 요청 제한에는 한시적인 메모리 집계와 이메일 요청 제한용 검증값을 사용합니다.

정보는 이용자의 입력·저장·연결 요청, 이용 중 통신, 선택한 제공처의 응답을 통해 처리합니다. 결제카드, 주민등록번호, 생체정보를 요구하지 않습니다. 자유 대화형 외부 AI로 회원 메모나 거래 기록을 전송하지 않습니다. 회원 기능은 만 14세 이상을 대상으로 하며, 만 14세 미만 아동의 정보가 수집된 사실을 알게 되면 보호자 확인 등 필요한 조치 후 삭제합니다.

3. 정보별 보관·삭제 기준

계정·회원 기록·서버 관찰 결과
회원 탈퇴 또는 해당 정보의 삭제 요청을 처리할 때까지 보관합니다. 본인과 요청 범위를 확인한 뒤 지체 없이 운영 데이터에서 삭제합니다. 단순 로그아웃이나 감시 중지는 과거 기록 삭제가 아닙니다.
거래소 연결 정보·API 키
연결을 삭제하거나 회원 탈퇴 요청을 처리할 때까지 보관합니다. 앱의 연결 삭제는 해당 API 키를 보관함에서 제거합니다. 이미 저장한 과거 신호·검토 기록은 별도 삭제 대상이며, 거래소에 발급된 키 자체를 폐기하려면 거래소에서도 철회해야 합니다.
로그인·인증 임시 정보
로그인 세션은 발급 후 12시간 동안 유효합니다. 이메일 인증 기록은 발급 후 10분간 유효하고, 발송 제한 집계는 목적에 따라 분·시간·일·31일 단위 만료 시각을 사용합니다. 만료된 서버 임시 정보는 서버 시작 시와 가동 중 30분 간격으로 정리합니다. 서버 중단 시에는 다음 시작 때 정리합니다. Telegram 연결용 임시 코드도 만료 후 제거하며 연결된 대화방 정보와 구분합니다.
일반 문의·오류 신고
처리 종료 후 최대 90일 이내에 운영자가 메일 본문·첨부·불필요한 업무 사본을 삭제합니다. 문의자가 먼저 삭제를 요청하고 추가 보관 사유가 없으면 더 일찍 삭제합니다. 삭제는 휴지통 이동에만 그치지 않고 계정에서 영구 삭제하는 절차를 포함합니다.
분쟁·법령에 따른 예외 보관
진행 중인 분쟁·수사·법령상 보존 의무가 있는 경우에는 해당 사유와 직접 관련된 최소 정보만 일반 이용 자료와 구분해 보관하고, 사유가 끝나면 삭제합니다. 현재 결제를 받지 않으므로 존재하지 않는 결제·환불 기록을 일괄적으로 장기 보관하지 않습니다.
브라우저 자료·외부 사업자의 운영 정보
브라우저 자료는 아래 ‘기기 저장’ 기준을 따릅니다. 호스팅·메일 사업자가 별도로 처리하는 접속·보안 로그와 복구용 사본은 해당 사업자의 처리 목적·법적 의무·삭제 절차에 따라 보관됩니다. 아래 업체별 안내를 통해 기준을 확인할 수 있으며, 이용자 요청 시 필요한 삭제·제한 요청을 함께 진행합니다.

운영자가 내려받는 개인정보 사본은 요청 처리에 필요한 범위로 제한하고 목적이 끝나면 삭제합니다. 복구용 사본에 삭제 대상이 남아 있는 경우 일반 서비스에 사용하지 않으며, 복원할 때 삭제 요청을 다시 반영해 해당 정보를 되살리지 않습니다. 외부 사업자의 물리적 백업까지 즉시 삭제된다고 보장하지 않습니다.

4. 열람·정정·삭제와 처리정지

  1. 기록은 해당 화면에서 확인·수정·삭제하거나 계정 설정의 ‘회원 기록 내려받기’를 이용할 수 있습니다. 내보내기는 모든 서버 설정과 운영 로그를 포함하는 전체 백업은 아닙니다.
  2. 계정 전체 삭제·열람·정정·처리정지 요청은 info.marketcop@gmail.com으로 계정 아이디와 요청 범위를 알려주세요. 전체 회원 탈퇴 버튼은 아직 제공하지 않으며, 고객지원에서 처리합니다.
  3. 다른 사람이 기록을 삭제하지 못하도록 계정 소유 또는 대리 권한을 확인합니다. 비밀번호·복구 코드 원문을 메일로 요구하지 않습니다. 필요한 확인 방법을 개별 안내합니다.
  4. 확인한 삭제 대상에는 계정·로그인 세션, 회원 기록, 이메일 연결, Telegram 연결, 가격·조건 감시, 포지션 연결과 저장된 API 키를 포함합니다. 감시를 중지한 후 관련 서버 자료를 삭제하고 결과를 안내합니다.
  5. 권리행사에 별도 비용을 받지 않습니다. 법령상 제한이나 타인의 권리 침해 우려로 요청 전부를 처리할 수 없는 경우 그 이유와 이의 제기 방법을 안내합니다.

전자 자료는 데이터베이스에서 삭제하고 잔여 기록을 정리하는 방법을 사용합니다. 불필요한 파일·메일은 복구 가능한 보관함에도 남기지 않도록 처리합니다. 본인이 내려받은 파일과 다른 기기의 로컬 기록, 거래소·Telegram 등 다른 서비스에 이미 남은 사본은 해당 기기나 서비스에서 별도로 삭제해야 할 수 있습니다.

고객지원 처리 외에 개인정보침해 신고센터 또는 개인정보 분쟁조정위원회에 상담·구제를 요청할 수 있습니다.

문의 메일을 보낼 때 발신 주소·본문·첨부·응답이 미국 등 Google이 운영하는 서버에 전달·보관됩니다. 마켓코파일럿이 관리하는 문의함에는 처리 종료 후 최대 90일 기준을 적용합니다. Google 시스템에서의 삭제는 별도 절차를 거치며, 일반적으로 약 2개월이 걸리고 암호화된 백업에는 최대 6개월 남을 수 있다고 Google이 안내합니다. 예외적 지연·법적 보관이 있을 수 있습니다. Google 개인정보처리방침과 문의 방법, 삭제·백업 보관 안내.

회원 자료의 싱가포르 보관을 원하지 않으면 가입·서버 저장 기능을 사용하지 않고 비회원 기능을 이용할 수 있습니다. 이미 가입했다면 고객지원으로 이전 중지·계정 삭제를 요청할 수 있으며, 서버 동기화와 서버 감시 이용이 제한됩니다. 사이트 방문이나 메일 발송 과정의 외부 사업자 통신까지 완전히 차단하려면 해당 접속·전송을 중단해야 합니다.

시세를 직접 조회하면 Upbit·Binance 등 제공처가 요청 정보와 통신 정보를 받을 수 있습니다. 포지션 연결은 선택한 거래소에 지갑·계정 식별자 또는 인증 요청을 전송하며, 제공처의 별도 정책이 적용됩니다. 회원 비밀번호나 메모를 시세 조회 항목에 넣지 않습니다. Telegram과 새 발송·결제·AI 제공처를 활성화하기 전에는 국외 처리 조건과 선택 방법을 갱신합니다. 외부 뉴스 원문은 해당 언론사 사이트의 정책을 따릅니다.

6. 기기 저장과 자동 수집

비회원 관심종목·메모·보유 기록·시나리오, 언어·표시 모드·차트 크기와 일부 시세 캐시는 브라우저 로컬 저장소를 사용합니다. 해당 기능에서 삭제하거나 브라우저의 이 사이트 저장 데이터를 지울 때까지 남을 수 있습니다. 회원 기록과 합치려면 앱의 가져오기 기능을 사용해야 하며 로그인만으로 모든 과거 기록을 업로드하지 않습니다.

로그인 토큰과 미전송 회원 변경은 탭의 세션 저장소에 저장될 수 있습니다. 브라우저가 탭을 복원하면 세션 자료도 복원될 수 있지만 서버 세션의 유효기간은 12시간입니다. 브라우저 저장을 차단하면 설정 유지·기록·로그인 기능이 제한될 수 있습니다. 사이트 데이터 삭제 전에 필요한 파일을 내려받으세요. 로컬 자료를 지워도 서버 회원 자료는 삭제되지 않습니다.

7. 광고와 맞춤 광고 선택

현재 실제 AdSense 광고와 Google Analytics를 실행하지 않습니다. 광고 자리는 요금제 체험용 예시입니다. AdSense 소유 확인 정보와 ads.txt 등록은 광고 송출이나 광고 추적 동의가 아닙니다.

향후 AdSense를 활성화하면 Google 및 제3자 광고 공급업체가 이 사이트와 다른 사이트의 이전 방문 기록을 바탕으로 광고를 제공하기 위해 쿠키 등을 사용할 수 있습니다. Google 광고 쿠키로 Google과 파트너가 맞춤 광고를 제공할 수 있으며 IP·페이지 주소 등의 정보가 처리될 수 있습니다.

Google 광고 설정과 참여 광고업체의 맞춤 광고 선택 도구에서 개인 맞춤 광고 설정을 관리할 수 있습니다. 맞춤 광고 해제는 모든 광고의 제거를 의미하지 않습니다. 실제 활성화 전에 사용 업체·처리 범위·필요한 동의와 거부 설정을 안내하며, 단순 방문을 추적 동의로 처리하지 않습니다. Google의 파트너 사이트 정보 처리 안내.

8. 보호 조치와 분석 기능

회원 비밀번호·복구 코드는 단방향 검증값으로 관리하며, 거래소 비밀 키는 암호화해 저장합니다. 회원별 접근 제한, 세션 만료, 로그인 요청 제한, 암호화된 웹 통신을 적용합니다. 운영상 접근은 필요한 담당자로 제한하고, 권리행사 처리 시 다른 회원 자료와 구분합니다. 회원 데이터나 비밀값을 공개 저장소·일반 오류 로그에 포함하지 않도록 관리합니다.
