1. 비회원 기록과 화면 설정

관심 종목, 메모, 보유·거래 기록, 가격 시나리오와 일부 검토 기록은 기능에 따라 현재 브라우저의 로컬 저장소에 남습니다. 언어, 간편/전문가 모드, 차트·창 크기 설정, 일부 시세 캐시도 같은 기기에 보관됩니다. 이 저장은 다음 방문 때 화면과 기록을 이어가기 위해 사용됩니다.

로그인 상태는 탭의 세션 저장소에 보관합니다. 회원 기록을 전송하지 못한 경우에는 같은 탭의 임시 저장소에 남아 재전송을 시도할 수 있습니다. 브라우저의 탭 복원 설정에 따라 세션이 복원될 수 있으며, 서버 로그인은 발급 후 12시간 동안 유효합니다.

로컬 기록은 해당 기능에서 삭제하거나 브라우저 설정에서 이 사이트의 저장 데이터를 지울 때까지 남을 수 있습니다. 저장 데이터를 지우면 복구가 어려울 수 있으므로 먼저 필요한 기록을 내려받으세요. 기기 데이터를 지워도 서버에 저장한 회원 기록은 삭제되지 않습니다.

2. 회원 기능에서 사용하는 정보

계정 관리
입력한 아이디, 비밀번호의 단방향 검증값, 복구 코드의 검증값, 내부 회원 식별자, 가입 시각, 로그인 세션의 검증값·만료 시각을 저장합니다. 로그인·복구와 회원별 기록 구분에 사용합니다. 비밀번호와 복구 코드 원문을 그대로 저장하지 않습니다.
선택해서 저장한 기록
관심목록·메모·검토 이력, 보유·거래 기록, 가격 계획·시나리오, 연구실 기록과 ETF 수급 기록 등 해당 기능에서 입력하거나 저장한 정보를 계정별로 보관합니다. 거래소 계정에서 자동으로 가져온 실제 체결 내역으로 간주하지 않습니다.
서버 관찰과 알림
등록한 가격·조건, 종목·거래소·통화, 관찰 시각과 결과 등을 저장합니다. 창을 닫은 뒤에도 등록된 서버 관찰이 이어질 수 있습니다. 로그아웃은 감시 종료가 아니므로 알림 화면에서 별도로 종료하세요.
선택 연결 기능
이메일 인증 기능이 제공될 때는 직접 입력한 이메일·인증 시각과 한시적인 인증 기록을 처리합니다. Telegram을 직접 연결하면 대화방 식별자와 연결 시각을 처리하며, 선택한 알림 내용이 Telegram으로 전송됩니다. 현재 발송 가능 여부는 앱의 연결 상태를 확인하세요.

기존 비회원 기록은 로그인만으로 모두 서버에 복사되지 않습니다. 계정 설정의 가져오기 안내와 미리보기를 확인한 뒤 직접 복사를 선택할 수 있습니다. 서버의 계정·기록은 로그아웃이나 브라우저 데이터 삭제로 없어지지 않으며, 현재 일정 기간이 지나면 계정 전체를 자동 삭제하는 기능은 없습니다.

거래소 포지션을 직접 연결한 경우

Hyperliquid 공개 지갑 주소 또는 Lighter 계정 식별자를 연결하면 해당 식별자, 연결 이름·관찰 기준, 조회된 포지션과 위험 관찰 기록을 처리합니다. Binance·Bybit의 조회 전용 API 연결을 선택하면 입력한 API 키와 비밀 키를 서버에서 처리하고 암호화 보관함에 저장합니다. 조회 과정에서는 해당 거래소의 인증 방식에 따라 요청을 전송합니다. 이는 수동으로 입력한 보유 기록과 별개의 선택 기능입니다.

API 연결은 앱의 전용 연결 화면에서만 진행하고, 키를 문의 메일이나 일반 메모에 적지 마세요. 거래소 쪽에서도 사용 권한을 확인하고 필요하지 않은 키는 철회할 수 있습니다. 감시 중지, 앱 연결 해제, 거래소 키 철회는 서로 다른 작업이며 과거 관찰 기록이 모두 함께 삭제된다고 간주하지 마세요.

3. 접속과 외부 서비스

소개 페이지와 웹 화면은 GitHub Pages, 회원 기록·일부 시세 및 뉴스 중계는 Railway에서 운영합니다. 접속 과정에서 IP 주소, 요청 주소, 브라우저 정보 등 통신 정보가 해당 서비스에 전달될 수 있습니다. 시세를 직접 조회하는 경우 Upbit·Binance 등 자료 제공처에도 조회 대상과 통신 정보가 전달됩니다. 회원 비밀번호나 저장 메모를 시세 조회 항목에 넣지 않습니다.

오류 문의를 이메일로 보내면 발신 주소, 메일 내용과 첨부 자료가 Gmail에 저장됩니다. 문의 확인과 답변을 위해 사용하므로 계정 비밀정보나 불필요한 개인 자료를 포함하지 마세요. 문의 메일의 삭제도 같은 주소로 요청할 수 있습니다.

각 외부 사업자는 자신의 서비스 정책에 따라 접속 정보 등을 처리합니다. 해외 사업자의 서비스를 포함하므로 국내에서만 처리된다고 안내하지 않습니다. 백업·로그 및 문의 메일의 보관·삭제 기준과 외부 사업자의 세부 처리 조건은 운영 설정과 함께 별도로 확정해야 하는 항목입니다.

2026년 11월 15일 운영 설정을 확인한 결과 회원 서버와 연결된 저장 볼륨의 배치 지역은 싱가포르입니다. 이는 서버 배치 지역이며 모든 접속·보안 로그나 외부 사업자의 전체 처리 위치가 같다는 뜻은 아닙니다. Railway 지역 안내

4. 현재 광고 상태와 쿠키

현재 실제 AdSense 광고와 Google Analytics를 실행하지 않습니다. 앱의 광고 공간은 요금제 화면 체험용 배치 예시입니다. 사이트의 AdSense 소유 확인 정보와 ads.txt 등록은 광고 송출이나 쿠키 사용 동의가 아닙니다.

향후 Google AdSense를 활성화하면 Google 및 제3자 광고 공급업체가 이 사이트와 다른 사이트의 이전 방문 기록을 바탕으로 광고를 제공하기 위해 쿠키 등을 사용할 수 있습니다. Google 광고 쿠키로 Google과 파트너가 맞춤 광고를 제공할 수 있습니다. 광고 요청 과정에서는 IP 주소·방문 페이지 주소 등의 정보가 처리될 수 있습니다.

개인 맞춤 광고는 Google 광고 설정에서 관리할 수 있습니다. 참여 광고업체의 맞춤 광고 선택 도구도 참고할 수 있습니다. 개인 맞춤 광고 해제는 모든 광고의 제거를 뜻하지 않습니다.

실제 광고를 활성화하기 전에 사용 업체·적용 범위와 필요한 동의·거부 설정을 안내하겠습니다. 이 페이지를 읽거나 앱을 이용했다는 이유만으로 광고 추적에 동의한 것으로 처리하지 않습니다.
