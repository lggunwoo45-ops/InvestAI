자료 없음·갱신 필요를 만났을 때

자료가 없다는 표시는 상승·하락 신호가 아닙니다. 어떤 근거가 빠졌는지 먼저 좁혀보세요.

가격이 움직여도 다른 자료는 늦을 수 있습니다

현재가는 실시간으로 도착해도 일봉, 파생 지표, ETF 수급, 뉴스는 서로 다른 주기로 수집됩니다. 화면 상단의 시세 연결 표시만으로 모든 분석이 최신이라고 판단하지 마세요. 각 항목의 출처·기준 시각·수집 상태를 읽어야 합니다.

자료 없음
해당 종목이나 기간의 자료를 확보하지 못했습니다. 지원하지 않는 시장이거나 수집 이력이 부족한 경우도 포함합니다. 값이 0이라는 뜻이 아닙니다.
갱신 필요
이전에 받은 자료가 현재 판단에 사용할 만큼 최신인지 다시 확인해야 합니다. 표시가 남아 있다고 새 조회가 성공한 것은 아닙니다.
실제·예시 시세
예시 모드는 기능 체험용입니다. 실제 시세와 같은 형식으로 보여도 현재 거래소 가격이나 투자 성과로 사용하지 않습니다.
조건 미충족
검사할 자료가 있었지만 정해진 조건에 맞지 않았다는 뜻입니다. 자료 부족 때문에 판단하지 못한 상태와 구분합니다.

확인 순서

  1. 종목과 시장을 확인합니다. Upbit 현물과 Binance 선물에서 제공되는 지표가 모두 같지는 않습니다. 통화·시장 표기가 맞는지 확인하세요.
  2. 설정에서 실제 시세 모드를 확인합니다. 시세 연결 확인은 공개 목록 응답을 확인하는 기능입니다. 특정 종목의 모든 지표 수집까지 보장하지 않습니다.
  3. 해당 항목을 갱신하고 결과를 읽습니다. 잠깐 기다려도 요청이 실패하면 오류 안내를 확인합니다. 연속으로 반복 요청하면 제공처의 요청 제한에 걸릴 수 있습니다.
  4. 원문과 비교합니다. 같은 거래소·가격 단위·시각의 자료끼리 비교합니다. 서로 다른 시장의 가격 차이를 앱 오류로 단정하지 않습니다.
  5. 오류를 제보합니다. 화면 이름, 종목·거래소, 발생 시각과 오류 문구를 고객지원으로 보내주세요. 다른 회원의 정보나 계정 비밀값은 제외하세요.
설정에서 연결 확인고객지원에 문의

뉴스는 원문에서 한 번 더 확인하세요

뉴스 목록은 제목·출처·발행 시각과 원문 링크를 제공하는 출발점입니다. 제목만으로 사건의 영향이나 가격 방향을 확정하지 마세요. 발행 시각과 실제 사건 발생 시각이 다를 수 있고, 이후 정정되거나 업데이트될 수 있습니다. 관련 기사도 같은 원자료를 인용한 경우 독립된 여러 근거가 아닐 수 있습니다.

기사의 외부 원문을 열면 해당 제공처로 이동합니다. 이 가이드는 언론사 기사 전문을 복사하거나 재배포하지 않습니다.

자료 공백을 남기는 이유

확인되지 않은 수치를 채워 넣으면 화면은 완성돼 보여도 잘못된 결론을 만들 수 있습니다. 누락된 지표가 판단에 중요한 경우에는 확인을 미루거나 다른 근거를 검토하세요. 기록을 남길 때도 당시 사용할 수 없었던 자료를 함께 적어두면 이후 결과를 공정하게 비교할 수 있습니다.
