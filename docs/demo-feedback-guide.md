# InvestAI v0.6.2 demo feedback guide

Thank you for testing InvestAI. This build is an investment-workspace preview, not investment advice, and it cannot place trades. Please include your Windows version, browser, and screen resolution with your answers.

## First-use questions

1. Was the first screen understandable?
2. Was it clear how to search for a symbol?
3. Was the chart readable?
4. Was the watchlist easy to use?
5. Did any content feel cut off?
6. Was scrolling natural on the Dashboard, Market, Discover, News, and AI Copilot areas?
7. Did the difference between LIVE and MOCK mode make sense?
8. What felt confusing?
9. What feature did you expect but could not find?

## How to report a problem

Please describe the page, the action you took, what you expected, and what happened instead. Add the approximate time and a screenshot if possible. For LIVE-mode issues, mention whether other websites worked at the same time. Never include passwords, exchange credentials, API keys, or financial account information.

## Current demo boundaries

- LIVE mode requires internet and currently supports public Upbit and Binance market data only.
- MOCK mode works offline; Korea and US instruments use mock data.
- Trading, authentication, accounts, backend storage, database features, and real AI are intentionally unavailable.
- The Windows launcher is unsigned, so SmartScreen may display a warning.
