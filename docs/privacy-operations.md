# 개인정보 운영 절차 — 2026-11-16

공개 방침: https://lggunwoo45-ops.github.io/privacy/

운영 명칭은 사용자가 승인한 **마켓코파일럿(Market Copilot)**이다. 개인정보 문의는 **info.marketcop@gmail.com**에서 운영자가 직접 담당한다. 법인·사업자 등록 또는 별도 직원이 존재한다는 뜻이 아니다. 현재 무료 베타에 적용하며, 광고·결제·외부 AI·메일 인증·Telegram 발송 활성화 전에는 실제 제공처와 동의·거부 절차를 다시 점검한다.

## 실제로 지킬 보관 기준

- 계정·회원 기록: 회원 탈퇴 또는 개별 삭제 요청 처리 시까지. 확인한 요청은 지체 없이 처리한다. 단순 로그아웃·감시 중지는 삭제가 아니다.
- 세션·이메일 인증·발송 제한·Telegram 연결 코드: 각 만료 시각이 지난 항목을 서버 시작과 가동 중 30분마다 정리한다. 연결된 대화방·정상 회원 자료는 유지한다. `cleanup_failed` 로그 발생 시 원인을 해결하고 다시 정리한다.
- 문의함: 운영자가 영업일마다 확인하고, 접수 후 3영업일 내 안내를 목표로 한다. 완료된 문의에 완료일을 표시하고 **처리 종료 후 최대 90일 이내** 본문·첨부·보낸 메일·업무 사본을 영구 삭제한다. Gmail 휴지통 이동만으로 완료 처리하지 않는다. 이 절차는 수동이며 메일 자동 삭제나 정기 자동화가 설치됐다는 뜻이 아니다.
- 문의자의 조기 삭제 요청은 필요한 본인 확인 후 처리한다. 분쟁·법정 보관 예외는 사유·최소 항목·종료 조건을 별도로 기록하고 목적이 끝나면 삭제한다. 결제를 받지 않으므로 가상의 결제 기록에 장기 보관 기간을 적용하지 않는다.
- 운영용 사본: 필요할 때만 만들고 사용 종료 후 삭제한다. 공개 저장소·스크린샷·CI 결과에 실제 개인정보를 남기지 않는다.

## 회원 전체 삭제 요청

이 절차는 **구체적인 회원의 확인된 권리행사 요청이 있을 때만** 실행한다. 이번 기능 준비나 배포는 기존 회원 자료 삭제의 승인이 아니다.

1. 아이디와 요청 범위를 확인한다. 아이디를 알고 있다는 사실만으로 삭제하지 않는다. 기존 인증된 세션에서 해당 회원만 가능한 임의 확인값을 기록하도록 안내하는 등 소유를 검증하고, 정상 계정 복구를 이용할 수 있으면 그 절차를 우선한다. 비밀번호·복구 코드·API 비밀 키 원문을 메일로 요구하지 않는다. 대리 요청은 별도로 권한을 확인한다. 확인 불가 시 안전한 추가 확인 방법과 사유를 안내한다.
2. 대상 내부 회원 ID와 연결된 저장소를 확인한다. 다른 회원의 자료를 출력하지 않는다. 요청자가 필요한 자료를 내려받을 수 있도록 안내하고, 서버 회원 기록과 각 기기의 비회원 기록·거래소 발급 키가 별개임을 설명한다.
3. 작업 시간을 안내하고 회원 서버를 정상 종료한다. 자동 재시작도 막고 기존 프로세스·읽기 연결이 모두 끝났는지 확인한다. 작업자는 연결된 영구 볼륨에 접근할 수 있어야 한다. 워커 임대가 만료될 때까지 기다린다. **살아 있는 서버 컨테이너에 삭제 명령을 그냥 실행하지 않는다.**
4. 기존 DB가 있는 절대 디렉터리를 확인한 뒤 아래 CLI를 확인 인수 없이 실행해 범위를 미리 확인한다. 경로·ID는 실제 승인 대상 값으로 대체한다. 새 DB를 생성하거나 경로를 추정하지 않는다.

```text
node cloud/privacy-admin.mjs ABSOLUTE_CLOUD_DIRECTORY MEMBER_ID
```

5. 사전 확인 결과가 맞을 때만 `--confirm-owner MEMBER_ID`를 붙인다. CLI는 활동 중 워커·알 수 없는 회원 테이블·이전 파일 저장소가 있으면 중단한다. 해당 원인을 조사하고 범위를 포함하기 전에는 우회하지 않는다. 현재 회원 감시·암호화 키 보관함은 SQLite에 포함된다.
6. 계정·세션·회원 기록·이메일 연결과 인증 요청·Telegram 연결·가격 감시·포지션 보관함·결과 추적 자료 삭제 및 DB 잔여 공간 정리를 확인한다. WAL 정리 오류가 나면 이미 행은 삭제됐을 수 있으므로 완료 메시지를 보내기 전에 남은 읽기 연결과 체크포인트를 해결한다. 서버 재개 후 다른 회원 자료의 개수·무결성을 확인하고 삭제된 ID가 다시 나타나지 않는지 확인한다. 운영자 작업 사본도 정리한다.
7. 실제 활성화된 백업 목록·저장 위치·삭제 가능 여부를 확인한다. 복구용 사본에 대상이 남으면 일반 조회에 사용하지 못하게 하고, 만료/삭제를 추적한다. 사본을 복원할 때 삭제 요청을 재적용해야 한다. 호스팅 사업자의 로그·사본은 필요한 삭제/제한 요청을 하고 답변을 기록한다. 확인되지 않은 물리적 삭제를 완료했다고 말하지 않는다.
8. 이용자에게 완료 범위와 남은 예외를 안내한다. 비밀값 없이 최소한의 처리 기록을 남기고 일반 문의 90일 기준을 적용한다. 여전히 복원 가능한 사본이 있다면 재삭제에 필요한 최소 식별 정보만 그 사본이 없어질 때까지 일반 이용 자료와 분리한다. 본인 기기의 로컬 자료와 거래소 발급 키 폐기는 별도로 안내한다.

## 외부 서비스 확인 사항

- 2026-11-16 Railway 서비스와 영구 볼륨 지역은 싱가포르로 확인했다. 지역 사실과 공급업체의 본사/지원 처리 지역을 혼동하지 않는다.
- 현재 Railway 자동 백업 설정은 이번 확인에서 조회하지 못했다. 켜져 있다거나 없다고 단정하지 않는다. 운영자가 콘솔의 Backups 탭을 확인하여 실제 주기와 보관 기간을 기록한다. 백업 기능을 새로 활성화하거나 유료 플랜을 구매하지 않았다.
- Railway 로그의 조회 가능 기간은 물리적 삭제 시점을 보장하지 않는다. 상위 요금제로 변경하면 이전 로그가 다시 보일 수 있다는 공식 안내를 따른다.
- 공급업체 계약 체결을 추정하지 않는다. Railway DPA는 별도 서명·체결 절차가 명시돼 있다. 가입만으로 체결됐다고 쓰지 않으며 운영자가 기존 계약 상태를 확인한다. 새 약관 서명이나 개인정보 처리계약 체결은 이 코드 배포에 포함하지 않았다.
- Gmail 문의 영구 삭제 후 Google 내부 삭제/백업 절차는 별도다. 일반 삭제 약 2개월·암호화 백업 최대 6개월 등 공식 안내와 예외를 공개 방침에 연결한다.
- 새 제공처·국외 이전·광고 활성화 전에 실제 항목, 국가, 시점/방법, 목적, 기간, 연락처, 거부 방법 및 적용 근거를 갱신한다. 필요 시 별도 동의를 받는다. 방침 링크나 방문을 동의로 취급하지 않는다.
