# 기간별 과열 참고 지표와 모바일 개선

2026-10-26. 기존 Bybit 저장 이력을 사용해 최근 7·30·90일과 마지막 관측값을 비교한다. 새 유료 공급원이나 외부 발송은 추가하지 않는다.

## 비교 방법

파생 지표 기록실의 조회 기간을 바꾸면 비교 범위도 변경된다. 펀딩은 확정 정산값의 절댓값, 미결제약정은 기초자산 수량을 각각 비교한다. 현재 값을 제외한 과거 표본 중 작은 값 수에 같은 값 수의 절반을 더한 뒤 표본 수로 나눈 백분위다. 모든 값이 같으면 50이며 새 최댓값은 100이다. 90 이상·10 이하를 높은 편·낮은 편으로 구분하는 서비스 내부 기준이며, 매매 확률·수익률·종합 위험 점수로 해석하지 않는다.

요청 기간의 90% 이상을 확보하고 최소 과거 표본 수(펀딩 14, OI 24)를 만족해야 표시한다. OI는 시간별 표본 수도 기간의 90% 이상이어야 한다. 펀딩은 관측 간격이 동일하고 12시간 이내인 기록만 비교하며, 간격 변화와 누락을 구분할 수 없으면 보류한다. 이는 기록에 보이는 간격의 일관성 검사이며 거래소가 발표한 정산 주기를 대신하는 보장이 아니다.

최신 수집 실패·조회 실패·지표 지연이면 점수를 숨긴다. 부족한 7일 자료를 30·90일 값으로 확장하지 않는다. 현재 저장된 버전으로 계산하므로 과거 시점의 매매 검증에는 사용하지 않는다. 1년 종합 과열도, 청산 조건, 펀딩 비용 반영은 별도 작업이다. 계산 버전은 `investai-relative-heat-1`이다.

- 종목 분석의 고정 최소 폭, 신호 설정과 결과의 좁은 열, 제목·도구막대 줄바꿈을 조정한다.
