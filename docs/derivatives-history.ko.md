# 파생 지표 기록실

2026-10-26: 사용자가 요청한 ETF 무료 자동화 가능성을 먼저 검토하고, 조건을 확인하지 못한 경우의 대안인 과거 지표 저장을 구현했다. 새 유료 API·서버·도메인 없이 기존 Railway 저장 공간을 이용한다. 기존 호스팅의 사용량 비용까지 무료라는 뜻은 아니다.

## ETF 검토 결과

- [Farside BTC 표](https://farside.co.uk/btc/)와 [ETH 표](https://farside.co.uk/eth/)는 공개돼 있으나 지속적인 자동 수집·공개 서비스 재표시 조건까지 확인하지 못했다. 무료 이용이 불가능하다는 단정은 아니다.
- [CoinGlass 공식 API 요금](https://www.coinglass.com/pricing)은 유료이며 상업용 구분이 있다.
- [SoSoValue 이용약관](https://sosovalue.gitbook.io/helpdocument/resources/terms-of-use)과 공개 API 소개만으로 무료 상업 서비스 재표시 조건을 확정하지 않았다. 제3자 무료 중계 서비스의 소개를 원자료 사용 허가로 간주하지 않았다.

따라서 ETF는 출처가 있는 수동 CSV 기능을 유지한다. 추정 보유량 변화로 확정 ETF 순유입을 생성하거나 무료인 것처럼 표시하지 않는다.

## 이번 제공 범위

- 기존 코인 23종의 Bybit USDT 무기한 선물. [확정 펀딩률](https://bybit-exchange.github.io/docs/v5/market/history-fund-rate)과 [1시간 미결제약정](https://bybit-exchange.github.io/docs/v5/market/open-interest)을 수집한다.
- 미결제약정 단위는 기초자산 수량(BTC, ETH 등). USD 환산액이나 방향별 포지션이 아니다. API의 `openInterest` 필드 기준이다.
- 펀딩은 정산 1회 비율이며 예상값·연환산값이 아니다. 종목별 정산 간격을 고정 8시간으로 가정하지 않는다.
- 방문자 유무와 무관하게 15분마다 종목·지표별 최근 7일을 재조회한다. 최대 200행으로 제한하고 페이지 초과·잘린 결과는 성공으로 처리하지 않는다. 실패한 지표만 오래된 상태가 되며 이전 값은 남는다.
- 최대 365일 보관, 화면에서 최근 7·30·90일 조회. 처음에는 실제로 받아온 최근 7일 자료만 있다. 수집 이전 장기 자료나 7일보다 오래된 공백은 자동 복원하지 않는다.
- OI는 조회 기간 전체에서 시간별 공백을 표시한다. 막 시작된 시각의 한 시간은 정상 발표 지연을 고려해 누락 판정에서 제외한다. 상장 이전과 장애를 임의로 구분하지 않고 모두 '미확보'로 표시한다. 펀딩은 변경 가능한 정산 간격 때문에 누락 개수를 추정하지 않는다.
- 간편 화면: 두 지표 설명·최근 값·24시간 전 같은 시각 OI 비교·추이. 전문가 화면: 지표 선택, 실제 시각과 최초 저장 시각, 페이지별 원자료, 누락 구간, CSV 내보내기.

## 저장과 시간 의미

`INVESTAI_RESEARCH_DIRECTORY`가 있으면 해당 절대 경로, 없으면 기존 `INVESTAI_CLOUD_DIRECTORY/research-history/derivatives.sqlite`를 사용한다. 둘 다 없거나 저장소를 열 수 없으면 503을 반환하며 임시 메모리 저장을 영구 저장처럼 표시하지 않는다. 회원 데이터베이스와 별개 파일이다.

SQLite WAL과 저장소 안의 임대 잠금으로 배포 전환 중 중복 수집을 방지한다. 저장 키는 종목·지표·거래소 기준 시각·실제 확인 시각이다. 동일값 재조회는 중복 저장하지 않는다. 값이 정정되면 새 확인 시각으로 버전을 추가하고 기존 버전도 보관한다. 거래소 범위는 이 파일 전체에 고정된 Bybit USDT 무기한이다.

`at`는 거래소 자료 시각, `knownAt`는 해당 버전의 실제 수집 시각이다. 저장소 읽기의 `knownAt` 제한을 통해 이후에 받은 자료나 정정값을 과거에 알고 있었던 값으로 쓰지 못하게 한다. **과거 신호 탐색의 조건 결합과 1년 종합 과열도 계산은 이번 범위에 포함하지 않았다.**

읽기 전용 API: `GET /api/research/derivatives?asset=BTC&days=7`. 허용 종목과 7·30·90일만 받으며 조회 요청은 외부 수집을 유발하지 않는다. 회원·거래 API 키나 개인정보는 수집하지 않는다. 고정된 거래소 공개 엔드포인트만 사용한다.

## 검증

자동 테스트는 숫자·출처·시각 검증, 수정 이력과 당시 알려진 값 조회, 원자적 저장, 중복 제거, 재시작, 누락 재수집, 실패 시 이전 자료 보존, 동시 수집 방지, 보관 기간, HTTP 경계 및 간편·전문가 화면을 확인한다. 실제 API 응답 및 배포 이후 공개 화면은 별도로 확인한다.
