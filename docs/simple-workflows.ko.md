# 기능별 심플 화면

심플 모드는 사이드바를 숨기는 설정이 아니라, 각 기능에서 하나의 판단과 다음 행동을 먼저 제시하는 화면이다. 전역 모드 변경은 현재 주소를 바꾸지 않으며 종목 선택, 보유 기록, 계산과 기록 입력을 공통 상태로 사용한다. 전문가 모드는 기존 필터·지표·차트·원본 근거를 제공한다.

| 기능 | 심플 화면 |
| --- | --- |
| 홈·후보 찾기 | 사용자가 요청한 실제 가격 검사, 최대 3개 후보, 이유·확인할 가격·주의 가격 |
| 일일 후보 기록 | 저장 시각과 당시 이유, 최신 분석으로 이동 |
| 마켓 | 이름 검색·관심종목 → 한 종목의 쉬운 분석. 휴대폰은 목록/분석 전환 |
| 종목 분석 | 코인은 핵심 판단·내 보유 기준, 주식은 요약·내 보유 상황·근거를 하나씩 선택 |
| 내 종목 | 평가손익 우선 카드, 보유 금액·거래 내역·목표가와 백업을 필요할 때 확인 |
| 뉴스 | 시장과 검색어 중심, 출처·발행 시각·원문·연결된 종목 분석 |
| 시장 지표 | 시장 심리 / 과거 변화 / 일정 / 청산 / ETF 수동 기록 중 선택 |
| 포지션 | 직접 계산 / 계좌 연결 / 공개 지갑 조회 중 선택 |
| 비용·프리미엄·신호·일지 | 기존 단계별 입력과 쉬운 해설 유지, 원본 계산과 기록 공유 |
| 알림 | 서버 / 열린 화면 / 포지션·신호·진입 조건 감시 중 선택. 작동 범위 명시 |
| 매수 계획 | 금액·수량 → 목표·손실 가격 → 예상 결과 |
| 과거 시험 | 종목·시작 금액 선택 → 실행 → 계속 보유한 결과와 비교 |
| 설정·도움말 | 화면·언어 / 알림 / 연결을 선택, 초보자 사용 경로 제공 |

## 후보 표시 기준

기존 실시간 검사 엔진을 사용한다. 같은 거래소·기준통화 안의 거래대금 상위 12개를 검사하고, 상승 방향·평소 이상의 거래량·과열 제외·손익비 1.5 이상·진입 구간 조건과 확인된 반대 근거 부재를 충족한 결과만 최대 3개 표시한다. 정렬은 거래대금 순서이며 수익 순위나 확률이 아니다.

데이터가 부족하거나 오래됐으면 제외하며 0개도 정상 결과다. 시세 수신 후 90초가 지나면 결과에서 제외한다. 예시 시세에서 실제 후보를 만들지 않는다. 주식 자동 후보, ETF 자동 수급, 자유 대화 AI 등 기존 미연결 기능을 새로 구현한 것으로 표시하지 않는다.

## 상태와 접근성

- `SimpleTasks`는 한 작업만 표시하되 다른 작업의 폼을 유지한다. 전문가에서는 같은 슬롯을 펼쳐 입력 초기화를 방지한다.
- 시장 선택·검색·관심목록은 기존 MarketPage 상태를 사용한다. 종목 변경 없이 전문가 화면으로 전환할 수 있다.
- 매수 계산과 보유 편집 값은 공통 부모 상태에 둔다. 과거 전략 시험·거래 내역 폼은 공통 래퍼 안에서 유지한다.
- 심플 메뉴는 추천·내 종목·알림이며 나머지 기능은 더 보기에 있다. 휴대폰 전문가 메뉴는 기존 네 개 기본 메뉴를 유지한다.
- 심플의 보조 AI 패널은 사용자가 열기 전에는 표시하지 않는다. 전문가의 저장된 열림 설정을 덮어쓰지 않는다.
- 숨긴 작업은 `hidden`으로 키보드 접근 대상에서 제외하고, 선택 버튼은 눌림 상태를 제공한다.

## 검증

전체 프런트엔드 검사 1,075개 통과 후 마지막 안내·계정 표시 변경에 대한 관련 검사 재실행. 신규 검사는 후보 미충족/만료 처리, 단계·모드 전환 시 계산 값 보존, 휴대폰 마켓 목록 복귀, 주요 10개 경로의 독립된 심플 화면을 확인한다. 기존 터미널 검사는 전문가 모드를 명시해 유지한다.

브라우저의 320px 화면에서 추천·마켓 목록/분석·연구실, 390px 화면에서 내 종목·매수 계산을 확인했다. 검색창의 최소 너비로 생긴 가로 넘침을 수정했다. 실제 휴대폰의 터치·키보드·운영체제 알림 검증과는 구분한다.
