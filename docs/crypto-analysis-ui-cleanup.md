# 코인 분석 화면 중복 정리

## 문제와 변경

코인 분석에서 다중 시간대 가격 계획과 이전 분석 요약·액션 상태·관심 단계·고정 비율 검토 범위가 함께 표시되어, 어느 결론과 가격을 기준으로 봐야 하는지 불명확했다.

- 내 종목 분석과 AI 탐색의 코인 상세는 기존 CryptoDecisionPanel을 현재 판단의 기준으로 사용한다.
- 코인 상세를 핵심 요약 / 상세 근거 / 내 투자 탭으로 나눈다. 핵심 요약을 기본으로 열며, 방향·다음 검토 행동과 가격 기준 3개·필요한 주의점만 표시한다.
- 상세 근거에는 추세·거래량·손익비, 시간대별 지표, 큰 체결·도미넌스, 일봉 자료와 후보 기록을 모은다. 내 투자에는 평단가·보유 기준·개인 입력·시나리오 저장을 모은다.
- 탭은 키보드 방향키와 Home/End로 이동하며 비활성 내용은 화면과 접근성 탐색에서 제외한다. 탭 전환 때 내용의 상태를 유지하여 입력 중 메모·시나리오와 기준 기록이 초기화되지 않게 한다. 다른 종목을 선택하면 요약 탭부터 시작한다.
- 코인을 선택한 뒤 검색은 종목 변경·검색으로 접고, 종목 정보와 페이지 제목을 압축한다. AI 탐색의 후보 수치·가격 이력·기록도 상세 근거 탭 안으로 옮긴다.
- 낮은 손익비, 임시 지지 기준, 매도 우세 등 필요한 주의 문구는 유지한다.
- 시간대별 지표·계산 근거와 큰 체결·비트코인 도미넌스는 간편/전문가 모드 모두 기본적으로 접는다. 전문가는 펼친 지표에서 이동평균 수치를 추가로 볼 수 있다.
- 코인 화면의 이전 요약·실행 준비도·관심 단계 카드와 고정 비율 검토 범위는 제거한다. 주식 화면의 기존 구성은 유지한다.
- 기존 저항 범위와 매도 가정 해제 기준은 계산 근거 안에 보존한다. 일봉 차트 참고 자료에는 상단 가격 계획과 시간대가 다를 수 있음을 표시한다.
- 데이터 부족은 시장 관망 판단과 구분하여 '분석 데이터 확인 중'과 시간대별 연결/품질 상태로 표시한다.
- 요약 복사는 화면과 같은 분석 엔진의 방향·가격 계획·근거·시각을 사용한다. 개인 평단가, 수량, 메모는 복사하지 않는다.

## 유지되는 기능과 범위

시나리오 저장·추적, 내 코인과 평단가 연결, 개인 입력 수정, 후보 기록과 기준 기록 갱신, 뉴스 참고 자료, 한국어/영어를 유지한다. 사용자가 저장한 목표·손절 기준은 자동 분석의 가격 계획과 별도로 유지한다. 저장 형식, 외부 API, 분석 알고리즘·임계값, 의존성, PC 실행 설정을 변경하지 않는다.

이번 변경은 정보의 우선순위와 중복 표시를 정리한다. 분석 정확도나 수익성을 개선했다고 주장하지 않는다. 접힌 자료도 기존 데이터 구독을 유지하며, 실시간 제공자의 응답 성공을 보장하지 않는다. 이전 분석 계산은 주식과 참고 기록 호환을 위해 남겨 둔다.

## 검증

- `npm run check`: 린트, 타입 검사, 전체 152개 테스트 파일의 816개 테스트, 프로덕션 빌드 통과.
- 회귀 테스트: 코인 간편/전문가 모드의 단일 결론, 상세 기본 접힘, 데이터 부족과 시장 대기의 구분, 요약 복사의 개인 정보 제외, 키보드 탭 이동, 비활성 탭 숨김, 탭 사이 개인 입력·시나리오 초안 유지, 종목 변경 시 요약 복귀, 평단가·기준 기록·한국어/영어·주식 분석 보존.
- AI 탐색 회귀 테스트: 코인 가격 계획이 있을 때 이전 고정 비율 검토 범위를 표시하지 않으며 일봉 참고 자료와 후보 기록을 유지.
- 로컬 브라우저: 실제 앱 구성에 명시적으로 표시한 검증용 가상 시세를 공급하여 정상/연결 대기 전환 확인 후 최종 탭 화면에서 요약·상세 근거·내 투자 전환, 저장 평단가·목표/손절 기준 접근 확인.
- 390px 화면에서 가격 카드 세로 배치와 줄바꿈 확인. 문서 너비 390/390, 본문 너비 326/326으로 가로 넘침 없음.
- AI 탐색의 검증용 저장 후보에서도 기본 요약 탭과 상세 영역을 확인. 화면 전체가 아닌 분석 영역 너비에 따라 가격 카드를 배치하여 좁은 후보 상세에서 숫자가 과도하게 분리되지 않도록 함. 마지막 반응형 스타일 조정 후 빌드 재통과.
- 검증용 페이지는 배포 소스에서 제외하고 삭제. 화면 캡처는 가상 시세이며 실거래 데이터 검증을 의미하지 않음.
- 기존 린트 경고 3개와 500kB 초과 번들 안내는 남아 있음. 새로운 오류 없음.
