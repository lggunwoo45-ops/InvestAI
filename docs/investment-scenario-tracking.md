# 투자 시나리오 저장과 변화 추적

기준: PR #84가 병합된 main `1fc2383`. 기존 포트폴리오·관심종목·거래 기록은 그대로 유지한다.

## 사용자 흐름

1. 종목 분석 또는 AI 탐색의 현물 코인 상세 분석에서 ‘이 분석으로 시나리오 저장’을 누른다.
2. 분석 시점·방향·기준 시간대와 관심 구간·목표·손절 가격을 검토하고 필요하면 수정해 저장한다. 가격은 `손절 < 관심 하단 ≤ 관심 상단 < 목표` 순서의 유한한 양수여야 한다.
3. 내 투자에서 저장 기준, 현재 관측 상태, 최근 변화 기록을 확인하고 수정·감시 중지/재개·삭제할 수 있다. 기준 변경은 명시적 저장 시에만 적용되며 그 시나리오의 이전 변화 기록을 비운다. 삭제는 별도 확인을 거친다.
4. 홈 간편모드와 간편모드 페이지의 ‘지금 확인할 변화’는 손절 접촉·추세 약화/하락 주의·목표 도달·매수 검토 조건 충족·가격 도달 순으로 최대 3개를 먼저 보여준다. 앱 내 알림은 어느 화면에서도 표시된다.
5. 보유 기록에서 분석으로 이동해 저장한 시나리오는 해당 기록이 여전히 유효하면 분석 링크에 보유 기록 연결을 유지한다. 시나리오 저장은 평단가·수량·목표가·손절가·매매 원장을 변경하지 않는다.

## 감시와 판정

- 업비트 KRW/BTC/USDT 현물, 바이낸스 현물 지원. 종목별 하나, 저장 최대 10개·동시 감시 최대 3개. 선물은 저장 대상에서 제외한다.
- 앱이 실행 중이고 해당 탭이 보이는 LIVE 모드에서만 감시한다. 숨김·모의 모드·삭제·일시 중지·수정·앱 종료 시 구독을 해제한다. 다시 활성화하면 새로운 기준 관측부터 시작한다.
- 기존 MarketDataService와 업비트 요청 간격 제어를 사용한다. 시나리오마다 저장한 기준 시간대 하나를 구독하며, 전체 3개 시간대 분석을 반복하지 않는다. 기존 화면과 별도의 구독이므로 최초 연결 시 추가 대기가 발생할 수 있다.
- 5초마다 관측하며 거래소 체결 시각이 최근 90초 이내인 유효 체결가격을 사용한다. 연결과 로컬 수신 시각도 정상이어야 한다. 저장된 종목 가격·카탈로그 가격·호가 수신만으로 도달 판정을 하지 않는다. 초기 연결, 최근 체결 부재와 시세 지연을 구분해 안내한다.
- 관심 구간 양끝·목표가 이상·손절가 이하를 포함한다. 이는 체결가격 접촉이며 실제 주문, 손절 실행, 봉 종가 이탈 확정 또는 수익 실현을 의미하지 않는다.
- 저장 당시 기준 시간대가 상승 추세였고, 그보다 새로운 완료 봉에서 기존 SMA20/50·ATR 규칙상 상승 추세가 아니면 ‘기준 시간대 상승 추세 약화’를 표시한다. 전체 다중 시간대 방향 점수가 뒤집혔다는 뜻은 아니다. 미완료·누락·지연 봉은 제외한다.
- 첫 관측, 재연결, 모드 전환, 15초 초과의 관측 공백과 시계 역행에는 현재 상태만 표시한다. 연속 관측 중 새 조건이 생겨야 알림·이력을 만든다. 같은 시나리오/조건은 5분 동안 반복 알림을 억제한다.
- 전역 최근 변화 60건을 저장하며 각 카드에서 최근 5건을 보여준다. 편집 시 이전 기준의 기록을 지워 다른 기준의 이력을 섞지 않는다.

## 가격 도달과 매수 검토의 구분

가격이 저장한 관심 구간 안에 있다는 사실만으로 매수 검토 조건 충족을 표시하지 않는다. 내 투자와 간편 카드에서 다음 상태와 근거를 함께 제공한다.

- **매수 검토 가격대 도달 · 반등 확인 대기**: 가격은 구간 안이지만 아래 반등 조건이 남았다. 다른 조건이 남으면 ‘추가 조건 확인 대기’와 다음 확인 항목을 표시한다.
- **매수 검토 조건 충족**: 구간 안에서 다섯 조건을 모두 통과했다. 저장한 손절 기준과 함께 매수를 검토할 수 있다는 의미다.
- **가격대 도달 · 하락 추세 주의**: 기준 시간대가 하락 추세이며 다른 조건보다 우선해 주의를 표시한다.
- **가격대 도달 · 분석 근거 확인 대기**: 체결가격은 확인했으나 완료 봉 근거가 부족하거나 지연되었다. 시세 자체가 없으면 기존 ‘실제 시세 확인 중’을 표시한다.

다섯 조건은 저장한 기준 시간대 하나에만 적용한다. 별도 API 요청을 추가하지 않고 기존 완료 봉 판독기를 재사용한다.

1. **상승 추세 유지**: 완료 봉 종가 > SMA20 + 0.1 ATR, SMA20 > SMA50 + 0.1 ATR이며 현재 체결가격도 SMA20 + 0.1 ATR 위에 있다.
2. **새 완료 봉에서 반등**: 저장·수정 시각보다 이후에 종료된 최신 완료 봉이 관심 구간과 겹치고, 저가가 손절보다 높고, 종가가 관심 하단 이상이며 시가와 이전 봉 종가보다 높다. 현재 체결가격도 이전 봉 종가 이상이어야 한다. 미완료 봉은 제외한다.
3. **거래량 1.2배 이상**: 최신 완료 봉 거래량 / 그 직전 20개 완료 봉 평균 거래량 ≥ 1.2. 비교 평균이 0이거나 누락되면 충족으로 간주하지 않는다.
4. **현재가 기준 손익비 1.5 이상**: `(목표−현재 체결가격)/(현재 체결가격−손절) ≥ 1.5`. 관심 구간 중간값으로 대신 계산하지 않는다. 수수료·세금·슬리피지는 제외한다.
5. **과열 아님**: Wilder RSI(14) < 70이며 현재 체결가격의 SMA20 위 이격이 2 ATR 이하다.

근거 펼침에서 각 조건의 충족·대기·확인 불가, 실제 거래량 배수·손익비·RSI, 완료 봉 시각을 보여준다. 단순 규칙 판정이며 적중률·수익률은 아직 검증하지 않았다. 전체 다중 시간대나 시장 전반의 종합 매수 판정을 대신하지 않는다.

연속 관측 중 조건 충족·하락 주의·조건 해제를 별도 이력과 알림으로 남긴다. 조건이 약해지거나 근거를 잃으면 기존 충족 표시와 충족 알림을 철회한다. 데이터 복구만으로 과거 충족 알림을 되살리지 않는다. 첫 관측·연결 공백·5분 중복 억제 규칙은 그대로 적용한다. 이력의 충족 기록은 당시의 관측이며 현재 상태는 카드에서 확인한다.

## 저장과 제한

별도 `investai.scenarios.v1` 키에 버전, 검증된 거래소/종목 식별자, 고정 가격 기준, 분석 시점과 방향, 감시 여부, 관측 이력을 저장한다. 다른 저장 키를 수정하지 않는다. 알 수 없는 버전·손상 데이터·중복 종목·고아 이력·가격 순서 오류·개수 초과는 읽기 또는 쓰기를 차단한다. 저장공간 오류를 알리며, 쓰기 직전에 원본을 비교해 감지된 다른 탭 변경을 덮어쓰지 않는다. localStorage는 데이터베이스 수준의 다중 탭 원자적 잠금을 제공하지 않는다.

브라우저 저장 삭제 시 사라지고 기기 간 동기화되지 않는다. 기존 내 코인 JSON 백업에는 시나리오가 포함되지 않으며 화면에서 안내한다. 서버 감시·OS 푸시·자동 주문·백테스트·수익 확률은 이번 범위에 없다. 5초 관측 사이의 짧은 접촉이나 비활성/절전/연결 끊김 구간의 움직임은 놓칠 수 있다. 여러 창·기기의 네트워크 호출을 전역으로 조율하지 않는다.

새 패키지·API 키·서버 설치·PC 개발 환경 변경은 없다. 기존 분석 계산은 변경하지 않으며 감시가 꺼진 시나리오에는 구독을 만들지 않는다.
