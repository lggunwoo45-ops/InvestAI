# 무료 베타 출시 준비 — 2026-11-02

이번 범위는 기존 웹사이트의 소규모 무료 베타다. 사업자와 결제 서비스가 아직 없으므로 실제 결제·구독 권한은 연결하지 않는다. 기존 가입 한도 50명을 유지한다. 초대 코드 검증 기능은 없으며 가입 허용 여부는 기존 서버 설정을 따른다.

## 이번에 연결한 기능

- 회원의 새 추천 검증 기록을 `accounts.sqlite`의 `opportunity_trials`에 보관한다. 계정별 최대 100건이며 오래된 기록을 임의 삭제하지 않는다. 회원 전체 내보내기에도 포함한다.
- `/api/cloud/opportunities` GET은 본인 기록만 반환한다. POST는 최신 가격 조건만 접수하며 결과·관찰값 업로드 및 기록 수정은 받지 않는다. 서버가 등록 시각·ID·다음 정각의 관찰 시작을 정한다. 같은 신호와 같은 종목의 겹치는 관찰은 제외한다.
- 앱을 닫아도 서버가 업비트·바이낸스 현물의 완료 1시간봉을 조회한다. 조회는 기록된 24시간 구간을 지정하므로 최근 120시간봉에 국한되지 않는다. 거래 없는 시간은 빈 구간으로 남기고 추측하지 않는다.
- 서버 중단 뒤 저장된 일정에서 재개한다. 거래소 오류·누락은 5분 간격으로 재시도하고 관찰 종료 후 7일까지 복구를 시도한다. 끝내 빠진 자료는 판정 불가로 남긴다. 동시에 최대 3개, 회차당 30건으로 요청량을 제한한다. 거래소 제한 시 대기한다.
- 목표·손절이 같은 봉에 닿으면 손실~이익 범위로 표시한다. 진입 구간 밖에서 시작하면 미진입으로 남긴다. 비용 가정과 가격 조건은 고정한다. 완료 결과는 다시 쓰지 않는다.
- 기존 브라우저 기록은 ‘이 기기 이전 기록’에서 보존한다. 자동 업로드하거나 서버 검증 이력으로 바꾸지 않는다. 비회원은 기존 기기 기록 방식을 계속 사용한다. 회원 요청 실패 시 기기 저장으로 몰래 전환하지 않는다.
- 시작 안내에서 회원 저장·동기화 미지원 문구를 수정했다. 회원 서버, 추천 관찰, 메일, 텔레그램은 실제 접속 시 확인한 설정을 표시한다. 설정 유무가 전달 성공률을 보증하지는 않는다.

## 운영상 남는 항목

인증메일과 텔레그램 발송은 운영 서버 설정이 아직 없다. 이메일 발송 없이 가입한 사용자는 일회용 복구 코드를 보관해야 한다. 메일·봇·결제 계정은 이번 변경에서 만들지 않았다. 새로운 유료 인프라도 추가하지 않았다. 기존 호스팅 이용료와 한도는 계속 적용된다.

등록한 계획은 사용자가 실행한 검색의 조건 스냅샷이다. 서버가 그 전략의 수익성을 인증하거나 모든 시장 추천을 독립 생성하는 것은 아니다. 서버는 이후 가격 수집과 계정별 보존을 담당한다. 가상 결과는 실제 체결·계좌 수익률이 아니며 유료 출시 전 충분한 관찰 표본, 운영 복구 점검, 사용자 검증이 필요하다.

## 배포 및 복구

기존 Railway 서비스와 `/data` 볼륨을 사용한다. 추가 테이블·인덱스만 생성하므로 이전 계정·감시 기록은 유지된다. 회원 기능 초기화 실패 시 상태 API는 503을 반환한다. 이전 코드로 되돌려도 새 테이블을 삭제하지 않는다. 프런트엔드는 서버가 `opportunityTrialsAvailable`을 제공하지 않으면 회원 새 기록 접수를 막고 기기 이전 기록은 계속 보여준다.

검증 범위: 계정 격리, 서버 접수 시각, 과거 결과 업로드 차단, 중복·한도·일괄 등록, 종료 후 관찰, 저장소 재시작, 누락 복구, 모호한 결과, 연결 오류·재시도 종료, 늦은 요청과 계정 전환, 기존 기기 기록 보존. 실제 회원의 거래 주문이나 외부 알림 발송은 하지 않는다.
