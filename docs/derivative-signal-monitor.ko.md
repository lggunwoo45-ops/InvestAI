# 파생 조건 자동 신호 감시

2026-10-26: 신호 탐색에서 선택한 펀딩 방향과 미결제약정 24시간 변화를 회원별 지속 감시 및 로컬 감시에 연결했다. 추가 유료 데이터 서비스는 사용하지 않는다. 기존 서버의 사용량 비용은 별개다.

## 사용과 범위

- 신호 탐색에서 가격 조건과 추가 지표를 선택하고 `선택한 신호 감시 시작`으로 등록한다. 웹에서는 로그인해야 서버 감시를 사용할 수 있다.
- 가격은 Binance USDⓈ-M, 추가 지표는 Bybit USDT 무기한이다. 등록한 조건은 고정되며 이후 화면 설정 변경으로 바뀌지 않는다.
- 두 지표를 선택하면 모두 충족해야 한다. 처음 확인한 봉은 기준만 잡고, 이후 미충족에서 충족으로 바뀐 완료 봉을 기록한다. 조건 유지 중 반복 기록하지 않는다.
- 봉 종료 전에 저장된 버전만 사용한다. 펀딩 12시간, OI 2시간 유효기간과 정확히 24시간 전 비교값 등 기준은 과거 탐색과 동일하다. 나중에 받아온 과거값이나 정정값으로 이미 처리한 봉을 다시 평가하지 않는다.
- 자료 부족은 미충족과 구별한다. 자료가 돌아온 조회에서는 기준만 다시 잡고 새 알림을 만들지 않는다. 조회 사이에 놓친 여러 봉도 재발송하지 않는다. 따라서 복구 직후 실제 충족도 알림에서 빠질 수 있다.
- 파생 조회 장애가 발생해도 가격 전용 감시와 기존 신호의 이후 가격 결과는 계속 처리한다. 가격 봉 자체에 공백이 있으면 기존 정책대로 진행 중 관찰을 판정 불가로 남긴다.
- 발생 기록에는 선택 지표의 값·원자료 시각·실제 저장 시각·판정 시각·출처·판단 버전을 보존한다. 화면과 Telegram에는 충족 당시 값과 판정 기준을 표시한다.
- Telegram은 회원 본인의 채널 연결과 감시별 선택이 필요하다. 발송 시도를 먼저 저장하며 성공 여부 불명은 재시작 후 자동 재발송하지 않는다. 이번 검증은 가상 전송으로 진행했으며 실제 수신 확인은 별도다.

## 연결 및 호환

공개 연구 서버의 기존 저장소 읽기를 감시 서버에 주입한다. 회원마다 수집기를 새로 만들지 않고 동일 요청은 공유 캐시로 합친다. Vite 개발/미리보기 역시 같은 수집기를 공유한다. 별도 `backend/monitor/server.mjs` 단독 실행에는 이 연결이 없으므로 파생 감시를 등록할 수 없다.

`derivativeSignalsAvailable`은 저장소 읽기 연결 여부이며 모든 종목에 충분한 자료가 있다는 뜻은 아니다. 연결이 없으면 UI와 서버 모두 등록을 막는다. 기존 필터 없는 감시와 `any` 조건은 이전과 동일한 정규화·지문을 유지한다. 새로운 필터 감시는 `investai-derivatives-asof-1`을 함께 고정한다.

## 검증

자동 검증: 조건 보존과 미연결 거절, 최초 기준 설정, 두 조건 결합, 지연 자료·정정·누락, 복구 및 재시작 중복 방지, 자료 장애 중 기존 결과 추적, 계정별 분리, 근거 보관, 가상 Telegram 메시지 및 불명 전송 재시도 방지. 실제 브라우저에서는 조건 등록·확인·종료 흐름과 배포 화면을 확인한다.

청산 조건, 1년 종합 과열도, 실제 펀딩 비용의 수익률 차감은 이번 범위에 포함되지 않는다.
