# 국내 주식 연결: 개인 시험 단계

현재 코드는 한국투자증권(KIS) REST API의 국내 주식 현재가·수정 일봉을 읽는 연결부입니다. **계정/API 키가 없어 실제 인증 시세와의 대조 검증은 아직 하지 않았습니다.** 자동 테스트는 재현용 응답으로 검증합니다. API 키를 설정했다는 사실만으로 공개 서비스에서 데이터를 배포해도 된다는 뜻은 아닙니다.

## 화면에서 사용하는 순서

1. `내 투자 → 내 주식`에서 회사 이름 또는 6자리 종목코드를 검색합니다.
2. `이미 갖고 있어요`를 열고 평단가(원), 수량(정수 주)을 저장합니다.
3. `내 주식`에서 여러 보유 기록을 보고 `이 주식 분석·수정`으로 이동합니다. 삭제는 별도 확인을 거칩니다.
4. `마켓 → 한국 주식`에서도 종목 선택 후 같은 조회 화면을 사용합니다. 종목 목록 자체에는 예시 가격을 넣지 않습니다.

설정이 없으면 검색·보유 기록 저장은 작동하며 가격·손익·차트 대신 연결 설정 안내가 나옵니다. 설정 실패를 모의 가격으로 대체하지 않습니다. 예시 모드는 기존 모의 주식 화면을 유지합니다. 내 주식 보유 기록 링크는 실제 자료용 화면으로 이동합니다.

## 개인 시험에 필요한 준비

- 본인 계정의 한국투자증권 Open API 사용 신청/권한을 확인하고 App Key 및 App Secret을 발급받습니다. 계좌 개설·약관 동의는 사용자가 직접 진행합니다.
- 키는 채팅, GitHub, 브라우저 저장소, `VITE_` 변수에 넣지 않습니다. 서버 프로세스의 `KIS_APP_KEY`, `KIS_APP_SECRET` 환경변수로만 전달합니다. 브라우저에는 종목코드와 공개 시세 결과만 오갑니다. 계좌번호는 사용하지 않습니다.
- 로컬 개발: 환경변수가 설정된 터미널에서 기존 `frontend`의 `npm run dev`를 실행합니다. `127.0.0.1` 또는 `localhost`로 접속하면 Vite가 같은 주소의 `/api/stocks/snapshot?symbol=005930`을 처리합니다. 외부 PC에서는 이 로컬 경로에 접근할 수 없습니다. 키를 담은 파일을 새로 만들거나 기존 PC 실행 설정을 바꿀 필요는 없습니다.
- 공개 사이트: 기본적으로 주식 서버의 공개 접근은 꺼져 있습니다. 서비스 제공/시세 재배포에 필요한 권한과 제공 방식, 비용을 확인하고 해당 방식이 승인된 경우에만 별도 배포합니다. 현재 연결부는 개인용 `custtype=P`를 사용하므로 제휴용 계약을 맺었다면 해당 인증·배포 요구사항부터 반영해야 합니다. `KIS_PUBLIC_ENABLED=true`는 계약이나 권한을 대신하지 않습니다.
- 승인된 공개 배포에서는 서버의 `UPBIT_ALLOWED_ORIGINS`에 실제 사이트 origin을 등록하고, GitHub 저장소 변수 `STOCK_RELAY_URL`에 HTTPS 서버 origin만 지정합니다(예: `https://example.test`, `/api/...` 경로 제외). 서버 키를 GitHub Pages 빌드에 넘기지 않습니다. 이 PR은 해당 변수/비밀/서비스를 설정하거나 배포하지 않습니다.

API 비용·이용 가능 범위는 신청 당시 공식 조건을 확인해야 합니다. 개인 API 사용 권한을 판매 앱 전체에 그대로 사용할 수 있다고 가정하지 않습니다. 기존 Railway 시험 서버의 무료 범위나 비용 상한도 이 코드가 보장하지 않습니다.

## 데이터와 분석 범위

- KOSPI/KOSDAQ의 저장된 회사 식별 목록. 신규 상장/상장폐지/이름 변경은 목록 갱신이 필요합니다.
- KRX 현재가 조회: 전일 대비 등락률, 누적 거래량, **서버 조회 시각**. 실시간 체결 스트리밍, NXT 통합 시세, 거래 가능 여부 확인은 제공하지 않습니다. 장 마감·휴장·거래 정지의 마지막 가격일 수 있습니다.
- 최대 100개 수정 일봉의 종가 차트와 최근 10개 일봉 표. 분봉, 호가창, 체결 목록은 국내 주식 화면에서 제공하지 않습니다.
- 오늘 일봉을 제외한 최근 20개 완료 일봉 평균과 비교합니다(±1% 이내면 평균 부근). 최근 봉이 10일 넘게 오래됐거나 봉이 20개 미만이면 흐름 판단을 보류합니다. 실제 체결 시점, 기업 실적·공시·뉴스를 종합한 매수/매도 판단이 아닙니다.
- 평단가·수량으로 평가금액, 평가손익, 수익률 계산. 수수료·세금 제외. 액면분할 등 기업행위는 보유 수량/평단가를 수동으로 수정해야 합니다.
- 주식 보유 기록은 `investai.stock-holdings.v1`에 최대 100개 저장합니다. 기존 코인/관심종목을 수정하거나 마이그레이션하지 않습니다. 손상된 저장소·쓰기 실패·다른 탭과의 충돌은 성공으로 표시하지 않습니다. 브라우저 삭제 시 사라지고 기기 간 동기화·백업 기능은 아직 없습니다.
- 자동 종목 추천/AI 탐색에는 조회하지 않은 주식의 가짜 점수를 넣지 않습니다. 국내 주식 전체 자동 순위/추천은 후속 범위입니다. 미국 주식은 기존 예시 데이터입니다.

## 속도와 사용량 보호

- 화면을 보는 동안 30초 주기. 숨긴 탭에서는 새 조회를 시작하지 않으며 화면을 나가면 타이머를 해제합니다. 이미 시작한 공유 요청은 제한된 시간 내 종료됩니다.
- 프런트엔드: 같은 종목 요청/결과 공유, 동시 2개, 대기 포함 최대 12개, 요청 20초 제한, 오류 재시도 대기. 내 주식은 한 페이지 최대 6개 기록만 조회합니다.
- 서버: 동일 종목 요청 공유, 시세 30초/일봉 5분 캐시(최대 256항목), 한 번에 한 제공사 조회 및 최소 1.1초 간격, 대기 최대 16개. HTTP는 전체 분당 120개/동시 4개 제한입니다. 서버 인스턴스가 여러 개면 각 인스턴스마다 적용됩니다.
- 인증 토큰 공유·만료 전 재사용, 토큰 발급 재시도 최소 1분, 제공사 오류 시 30초 대기. 키·토큰·원문 오류를 응답/로그에 넣지 않습니다. 잘못된 날짜/가격/봉과 과대 응답은 거부합니다.
- 이 제한은 재시작 간 누적 예산, 악성 사용자의 가용성 보장, 호스팅 비용 상한이 아닙니다. 인증된 사용자별 쿼터와 공개 서비스 계약은 상용 출시 전에 별도로 필요합니다.

## 실제 연결 후 수용 확인

1. 본인 API 권한으로 로컬에서 삼성전자·SK하이닉스 및 KOSDAQ 한 종목을 조회하고 증권사 화면과 현재가·전일 대비·일봉을 비교합니다. 장중/장마감/휴장일을 구분합니다.
2. 다른 종목 이동 중 늦은 응답, 연결 끊김, 재시도, 서버 재시작 후 토큰 재발급 제한을 확인합니다. 현재 토큰 캐시는 메모리 기반이라 여러 서버로 수평 확장하지 않습니다.
3. 보유 기록 2개 이상 저장·수정·삭제 후 새로고침/다른 메뉴 왕복, 가격 누락 시 손익 미표시를 확인합니다.
4. 공개 제공 권한과 서비스 방식을 확정한 뒤 서버/웹사이트를 따로 승인·배포합니다. 실제 배포 origin에서 CORS와 시세/일봉 응답을 확인합니다.
