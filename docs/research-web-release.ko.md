# 연구 기능 공개 웹 배포

기존 GitHub Pages와 Railway 시세 중계 서비스에 연구 기능을 통합한다.

## 공개 웹에서 제공

- 심플·전문가별 신호 탐색 화면, 30개 방향별 조건, 9개 시간 간격
- 완료된 과거 봉 1,000/3,000/5,000개를 사용한 조건 검색과 이후 가격 관찰
- 신호 조합 저장·URL 공유, 검토 기록, 직접 입력한 포지션·비용 비교
- 저장 없는 공개 지갑 조회와 화면을 켜둔 동안의 브라우저 가격 알림

## 현재 PC 전용

거래소 API 키 보관함, 지속적인 계좌·신호·가격 감시, 감시 결과 기록과 Telegram 발송은 로컬 서버에서만 제공한다. 공개 서버에는 `/api/monitor`를 연결하지 않는다. 웹 화면은 사용 불가능한 계좌 입력·등록 폼과 감시 건수 대신 가능한 기능을 안내하며 개인 감시 서버를 반복 조회하지 않는다. 개인 키나 로컬 원장은 배포 파일에 포함하지 않는다.

사용자별 로그인·저장소·비밀키 관리가 구축되기 전에는 이 PC 전용 기능을 공동 공개 서버로 옮기지 않는다. 기존 PC 연결과 웹 기록은 동기화되지 않는다. 기록과 프리셋은 해당 브라우저에 저장되며 실제 주문은 실행하지 않는다.

## 배포와 확인

1. 프런트엔드 검사·테스트·Pages 경로 빌드와 백엔드 테스트를 통과한 변경을 main에 병합한다.
2. 기존 Railway 서비스의 연결 브랜치를 main으로 맞추고 `backend/market-data/Dockerfile`로 배포한다. 리소스·요금제·시세/뉴스 환경 변수는 유지한다.
3. `/api/research/health`, `/history`, `/snapshot` 응답, 허용된 사이트의 CORS, `/api/monitor` 비공개 여부를 확인한다. 외부 데이터 미제공은 실제 미제공으로 표시한다.
4. GitHub Pages 배포 결과와 `/InvestAI/research/` 직접 진입, 신호 탐색 및 포지션·알림 화면을 확인한다.

별도 국내 주식 개발 브랜치와 유료 결제는 이 릴리스 범위에 포함하지 않는다.

## 기록에서 가격 알림으로 이어가기

- 작성 중인 메모를 종목별로 이 브라우저에 임시 보관한다. 화면 이동·새로고침 후 이어 쓸 수 있으며, 검토 기록 저장에 성공하면 임시 메모를 비운다. 저장 실패는 화면에 알린다.
- 검토 기록에서 가격 알림으로 이동하면 선택한 메모와 당시 가격을 표시한다. 해당 브라우저에 없거나 종목이 다른 기록은 연결하지 않는다.
- 가격 조건 저장에 성공하면 화면의 1분 간격 갱신도 켠다. 재방문 시 기존 조건과 원래 기록을 복원하며 갱신 상태를 표시한다.
- 관측한 가격 통과에는 당시 조건 가격과 메모를 함께 남긴다. 첫 진입·자료 실패 후 재연결은 새 기준으로 시작하며, 같은 관측을 중복 기록하지 않는다.
- 웹 알림은 선택한 종목의 알림 화면이 열린 동안만 동작한다. 휴대폰 푸시나 상시 서버 감시로 확장한 릴리스가 아니다.
