# 코인 방향·가격 계획 분석

## 사용 흐름

- 종목 분석에서 코인을 선택하면 매수 우세 / 중립·방향 혼재 / 매도 우세와 다음 행동을 먼저 표시한다.
- 간편모드에서는 기존의 반복적인 요약·고정 비율 범위 카드를 숨긴다. 전문가는 기존 상세 분석을 계속 사용할 수 있다.
- AI 탐색에서 선택한 코인에도 동일한 분석을 제공한다. 간편 후보의 상세 링크는 해당 종목 분석으로 연결한다.
- 저장 평단가·수량은 가정 해제 가격에서의 예상 평가손익에 사용한다. 여기서 입력을 바꿔도 포트폴리오 원장은 수정하지 않는다.

## 방향 계산

기존 MarketDataService에서 1시간·4시간·일봉을 받아 브라우저에서 계산한다. 상위 화면의 일봉 구독을 재사용하고 1시간·4시간 구독을 추가한다. 종목/시간대 변경 및 화면 이탈 시 해제하고 이전 구독의 늦은 응답은 무시한다.

유효한 OHLCV와 **완료된 봉만** 사용하며, 최근 50개 봉이 연속이어야 한다. 실제 데이터·연결 정상·수신 후 90초 이내·마지막 완료 봉이 해당 주기의 1.5배 이내인 시간대만 인정한다. 미래 시각, 모의 데이터, 누락 봉, 연결 끊김은 원인을 표시하고 우세 계산에서 제외한다. 신선도는 화면에서도 10초마다 다시 확인한다.

- 종가 > SMA20 + 0.1 ATR, SMA20 > SMA50 + 0.1 ATR: 상승 추세
- 반대 정렬: 하락 추세. 나머지: 횡보·혼재
- 상승 +1, 하락 -1, 중립 0에 1시간:4시간:일봉 = 1:2:3 가중치 적용
- 유효 시간대 2개 이상 및 유효 가중치 합 대비 방향 점수 +0.5 이상이면 매수 우세, -0.5 이하면 매도 우세
- RSI14와 ATR14는 Wilder 방식. 거래량 배수는 마지막 완료 봉 / 직전 20개 완료 봉 평균
- RSI 70 이상 또는 SMA20 대비 2 ATR 초과 이격은 추격 경고에 사용하며 매도 예측으로 뒤집지 않는다.

일봉 상승·단기 하락 등 충돌을 함께 표시한다. 시간대 하나 또는 도미넌스 실패가 다른 정상 근거를 숨기지 않는다. 최소 근거를 충족하지 못하면 합산 방향과 가격 계획을 보류한다.

## 가격 계획

4시간, 일봉, 1시간 순으로 유효 기준 시간대를 택한다. 최근 최대 60개 완료 봉에서 좌우 2개 봉보다 낮은 저점/높은 고점을 피벗으로 본다.

- 현재가 아래 가장 가까운 피벗 저점. 없으면 최근 20개 봉에서 현재가 아래의 가장 가까운 저가를 **임시 관찰 기준**으로 사용한다.
- 매수 관심 구간: 기준 저점 ±0.25 ATR, 상단은 현재가 이하
- 매수 가정 해제: 기준 저점 -1 ATR
- 반등 저항: 현재가·관심 구간 위의 가장 가까운 피벗 고점, 없으면 최근 20개 봉의 고가
- 관측 저항이 없으면 현재가 +2 ATR의 변동 폭 확장 기준을 사용하고, 관측 저항과 명확히 구분한다.
- 저항 구간: 저항 기준 ±0.25 ATR. 매도 우세 재검토: 저항 기준 +0.5 ATR
- 손익비: (저항 기준 - 관심 구간 중간값) / (관심 구간 중간값 - 가정 해제 가격)

유한한 양수·가격 순서를 검증한다. 유효 구간을 만들 수 없으면 임의 숫자를 채우지 않는다. 하락 추세에서는 지지 접촉만으로 진입하지 말고 반등 저항과 추세 회복을 확인하도록 안내한다. 보유손익과 손익비는 수수료·세금·슬리피지를 제외한다. 거래소 주문 단위에 맞춘 지정가나 자동 주문이 아니다.

## 대형 체결

기존 거래소 스트림의 **최근 최대 20건** 중 5분 이내 유효 체결을 사용한다. 동일 ID를 중복 제거하고 매수/매도 방향과 가격×수량을 계산한다. 최소 10건, 최근 체결 60초 이내가 필요하다.

표본 금액의 75백분위 이상이면서 중앙값의 1.5배 이상인 체결을 상대적 대형 체결로 정의한다. 대형 체결 3건 이상일 때 금액 기준 매수 비중 60% 이상은 매수 우세, 40% 이하는 매도 우세, 사이 값은 균형이다. 기준 금액·표본 건수·시각 범위를 같이 표시한다.

이는 전체 5분 거래 집계, 절대 규모의 기관 거래, 개인/기관 신원, 고래 지갑 매집·분산, 온체인 순유입이 아니다. 업비트 BID/ASK 및 바이낸스 maker 플래그는 기존 제공자가 정규화한 체결 방향을 사용한다. 공개 실시간 체결만 필요하며 지갑 주소나 거래소 계정 연동은 없다.

## BTC 도미넌스

CoinPaprika의 공개 `GET /v1/global`에서 BTC 시가총액 비중, 전체 시장 시가총액 24시간 변화, 제공 시각을 읽는다. 브라우저에서 직접 요청하며 키·쿠키·포트폴리오·메모는 보내지 않는다. 8초 제한, 10분 메모리 캐시, 중복 요청 공유, 실패 시 60초 재시도 제한을 적용한다.

비중 0~100%, 미래 시각/1시간 초과 지연 등을 검증한다. 로컬 저장소 `investai.market-dominance.v1`에 공개 집계값만 최대 192개/26시간 보관한다. 저장소 오류가 있어도 현재 값을 표시한다. 최초 사용에는 과거 변화율을 만들지 않는다. 실제 관측 기록이 30분 이상 쌓인 후 최대 26시간 범위에서 24시간에 가까운 기록과 비교하고 **정확한 비교 시각 및 %p**를 표시한다. 전체 시가총액 24시간 변화와 도미넌스 변화는 별개다.

비중 상승을 BTC 가격 상승이나 자금 유입으로 단정하지 않는다. 도미넌스는 시장 해석 보조 정보이며 방향 합산 점수에 섞지 않는다. CORS·제공자 장애·과거 데이터 부족 시 상태를 설명하고 가격 분석은 유지한다. 외부 무료 API의 호출/사용 조건은 운영 규모에 맞춰 확인해야 한다.

## 범위와 다음 단계

- 후보 목록의 기존 24시간 스냅샷 정렬은 유지한다. 이번 변경은 선택한 종목의 상세 분석이며 모든 코인을 동시에 정밀 스캔하지 않는다.
- 업비트 브라우저 요청 간격 제한을 유지한다. 최초 카탈로그·3개 시간대 연결에는 대기 시간이 발생할 수 있다.
- 이번 값은 해석 가능한 규칙 기반 분석이며 학습한 예측 모델, 적중률 검증, 과거 성과 백테스트가 아니다. 우세를 수익 확률로 표시하지 않는다.
- 온체인 고래 주소/거래소 입출금, 장기 도미넌스 히스토리, 펀딩·미결제약정·청산 위험, 거래비용 포함 워크포워드 검증은 후속 범위다.
- 새 패키지, API 키, 유료 AI 호출, 서버 설치, PC 환경 변경은 없다. 기존 포트폴리오/관심종목/원장 저장 형식은 유지한다.

## 검증

단위·화면 테스트: 알려진 RSI 값, ATR/이동평균/거래량 계산, 상승/하락/중립, 시간대 충돌/부분 실패, 미완료·미래·누락 봉, 오래된 연결의 우세 철회, 가격 순서/손익비, 대형 체결 방향/중복/신선도, 도미넌스 검증/캐시/실패/실제 관측 비교, 보유손익, 모의 데이터 차단, 시간대 변경 시 구독 해제 및 늦은 응답 차단, 간편 후보 연결을 포함한다.

2026-10-20 로컬 검증 결과:

- `npm run check`: 145개 테스트 파일 / 757개 테스트 통과, 타입 검사·린트·배포용 빌드 성공. 기존 린트 경고 3개와 500 kB 초과 번들 경고 유지.
- CI의 프록시 15개, 백엔드 9개, 로컬 AI 게이트웨이·Pages 경로 검사 4개도 통과.
- 실제 공개 시세를 사용하는 로컬 브라우저에서 BTC/KRW 가격 구간·부분 시간대 제외, Binance BTCUSDT 3개 시간대, CoinPaprika 현재 비중·시각 표시 확인.
- 브라우저 검증 시 체결 피드의 마지막 체결이 오래된 상태여서 대형 체결 우세를 보류하고 시각을 표시했다. 정상 매수·매도 체결 집계는 결정적 테스트 데이터로 검증했다.
- 간편모드 전환, AI 탐색 → 선택 종목 분석 이동, 390px 화면에서 문서·새 패널의 가로 넘침 없음 확인.
- 고가가 관심 구간과 겹치면 다음 유효 저항을 선택하는 회귀 검사, 타이머 사이 수신 체결의 시각 처리, 오래된 체결 안내도 포함한다.
