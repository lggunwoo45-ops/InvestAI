# 내 투자 거래 기록과 백업·복원

## 이번 변경

기존 내 코인을 시작 보유 기록으로 삼아 이후 매수·매도를 기록한다. 거래소 주문은 실행하지 않는다. 추가 매수 시 이동평균 평단가와 수량을 계산하고, 매도 시 남은 보유량과 기록된 실현손익을 계산한다. 기존 목표가·손절 기준가와 종목 분석 연결은 유지하며 보유 종료 기록은 현재 보유 합계와 분석 연결에서 제외한다. 다크모드와 전체 UI 교체는 포함하지 않는다.

- 매수 원가 = 체결 단가 × 수량 + 입력한 기준통화 수수료
- 매수 후 평단가 = (기존 원가 + 매수 원가) / 매수 후 수량
- 매도 실현손익 = 체결 단가 × 매도 수량 − 입력 수수료 − 매도 수량의 이동평균 원가
- 부분 매도는 남은 평단가를 유지한다. 전량 매도 후에도 거래 내역과 실현손익은 보존하며 다시 매수할 수 있다.
- KRW, BTC, USDT 등 서로 다른 기준통화를 합산하지 않는다. 현재 보유 평가손익과 기록된 실현손익은 별도로 표시한다.

## 기록과 정정

먼저 기존 코인 추가 화면에서 시작 평단가·수량을 저장한다. 각 보유 기록의 거래 추가에서 매수/매도, 체결 단가, 수량, 수수료, 거래 일시를 입력하고 결과를 확인한 뒤 저장한다. 시작 보유 이전의 매매 내역과 실현손익은 알 수 없으므로 추정하지 않는다.

거래 일시는 시간 순서로 입력하며 같은 일시는 입력 순서를 따른다. 미래 일시, 초과 매도, 음수 수수료, 매도금액을 넘는 매도 수수료, 유효하지 않은 숫자와 계산 범위 초과를 거부한다. 거래가 있는 기록의 평단가·수량은 직접 수정할 수 없다. 마지막 거래부터 취소해 정정하며 모든 거래를 취소하면 기존 보유 수정 기능을 다시 사용할 수 있다. 목표가·손절 기준가는 계속 수정할 수 있다. 보유 기록 전체를 삭제하면 해당 거래 내역과 실현손익도 삭제되며 확인 화면에 이를 안내한다.

## 저장 호환성

기존 `investai.portfolio.v1` 키를 사용한다. 읽기만으로 기존 데이터를 바꾸지 않으며 version 1 기록을 계속 지원한다. 거래가 포함된 저장은 내부 schema version 2를 사용한다. 이전 앱이 거래로 계산한 잔고를 덮어쓰지 않도록 이전 버전에서는 해당 데이터를 읽거나 수정할 수 없다. 이전 배포로 되돌릴 때 거래 내역이 포함된 데이터를 version 1로 임의 변경하면 안 된다.

저장된 잔고는 거래 내역을 재계산한 결과와 일치해야 한다. 손상 데이터, 알 수 없는 버전, 저장공간 부족, 감지된 다른 탭의 변경 시 원본을 덮어쓰지 않는다. 다른 탭의 저장 이벤트를 받으면 거래 입력과 복원 미리보기를 초기화한다. 로컬 저장의 읽기/쓰기 확인은 데이터베이스 수준의 동시 트랜잭션 잠금은 아니다.

## 백업·복원

JSON 파일에 보유 기록, 목표가·손절 기준, 거래 내역을 담는다. 관심종목과 기타 앱 설정은 제외한다. 파일은 암호화되지 않으며 서버에 업로드하지 않는다. 브라우저 데이터 삭제나 기기 변경 전에 사용자가 백업 파일을 보관해야 한다.

복원은 파일 검사와 추가/건너뜀 개수 미리보기 후 사용자가 적용한다. 현재 기록에 없는 ID만 추가한다. 같은 ID와 같은 내용은 건너뛰며, 같은 ID의 내용이 다르면 전체 복원을 중지한다. 기존 거래를 과거 백업으로 덮어쓰는 복구 방식은 제공하지 않는다. 빈 브라우저에서는 전체 백업을 복원할 수 있다. 현재 로컬 저장 자체가 손상된 상태에서는 원본 보존을 위해 복원을 차단한다.

최대 10 MiB 파일, 보유 기록 1,000개, 기록당 거래 1,000개, 전체 거래 10,000개를 검증한다. 실제 브라우저 저장 한도는 더 작을 수 있으며 저장 실패를 알린다. 가져온 거래도 재계산해 잔고 조작과 초과 매도 등을 거부한다.

## 범위와 제한

- 현물 보유의 수동 기록이다. 거래소 연동·주문·자동 알림·클라우드 동기화는 없다.
- 입력한 기준통화 수수료만 반영한다. 다른 코인으로 낸 수수료, 세금, 환율, 세무 신고용 손익은 지원하지 않는다.
- JavaScript 유한 숫자로 계산한다. 부동소수점의 상대 오차 수준만 전량 매도 잔여량에 허용하며, 정밀 회계 원장으로 사용하도록 설계하지 않았다.
- 모든 과거 거래를 자유롭게 편집하는 대신 마지막 거래부터 취소한다.

## 검증 결과

- `npm run check`: lint, TypeScript, 테스트 142개 파일 / 734개 테스트, production build 통과.
- 기존 lint 경고 3개와 500 kB 이상 번들 경고 유지. 새로운 오류 없음.
- 자동 검증: 수수료 포함 추가 매수, 부분/전량 매도, 재매수, 마지막 거래 취소, 작은 수량·숫자 범위, 날짜·중복 ID, 저장 버전 호환, 변조 데이터, 할당량·다른 탭 충돌, 복원 미리보기·중복·비동기 파일 읽기 중 변경.
- 로컬 브라우저의 가상 보유 기록: 0.1 BTC × 100,000,000 KRW에서 0.1 BTC × 120,000,000 KRW 추가 매수 → 0.2 BTC / 평단가 110,000,000 KRW. 0.1 BTC × 125,000,000 KRW 매도와 수수료 1,000 KRW → 잔여 0.1 BTC / 실현손익 1,499,000 KRW 확인.
- 실제 백업 다운로드 파일에 해당 보유량·평단가·거래 2건이 포함됨을 확인. 같은 파일 선택 시 추가 0 / 동일 기록 건너뜀 1과 적용 버튼 비활성화 확인.
- 데스크톱 및 390 px 모바일 화면 확인. 모바일 문서 너비 390 px, 가로 넘침 없음.
