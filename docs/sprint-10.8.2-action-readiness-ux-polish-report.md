# Sprint 10.8.2 — Action Readiness UX Polish

## What was improved

Action Readiness now presents the existing deterministic status in a clearer beginner-friendly hierarchy without changing its safety rules or calculation. The card separates state, signal clarity, and data mode, then explains the status, review conditions, next checks, and safety boundary.

## Action card hierarchy

The top row contains a single status badge, a separate Signal clarity badge, and a data-mode badge. The main heading identifies the card as Current action status in Simple Mode or Action readiness in Expert Mode. A short status helper follows, then three scannable sections for why the status exists, conditions to check, and conditions to avoid. Next checks and the non-instruction safety note remain at the bottom.

Simple Mode limits each list to at most three items. Expert Mode keeps the same readable structure and adds the rule basis.

## Status helper text

All six safe statuses now have short English and Korean explanations:

- Decision pending
- Waiting / checking conditions
- Watch zone
- Conditional approach possible
- Chase caution
- Sharp-drop rebound caution

The text explains evidence state and confirmation needs without transaction instructions or outcome claims.

## Mock/demo workflow preview

Mock and demo data remains gated to Decision pending. The card now identifies it as a workflow preview, explains that it is for understanding the analysis structure, and lists the live data, market fields, and source-linked news that would need verification. It does not expose zones or percentage ladders.

## Signal clarity wording

Strength is presented as Signal clarity / 판단 명확도 with Low clarity, Medium clarity, High clarity and Korean equivalents. Its helper explicitly says the value describes classification clarity, not expected return or confidence.

## Expert rule basis

Expert Mode displays a typed, rule-based explanation with:

- Data quality
- Movement state
- Candidate evidence
- News state
- Asset type

These values come from the existing deterministic profile. They are not generated by a model and do not use personal notes, average price, or review intent.

## Visual tone

Muted neutral, blue/teal, and amber treatments distinguish pending, observation, conditional, and caution states. No state is styled as an affirmative transaction signal, and caution states avoid alarm styling.

## Korean and English coverage

Status helpers, hierarchy labels, workflow-preview copy, data-mode labels, rule-basis fields, clarity wording, next checks, and safety notes are available in both languages.

## Safety wording

The card preserves the rule-based, non-instruction disclaimer. No percentage ladder, exact action price, transaction signal, return promise, real AI inference, or fabricated data was added.

## Tests

Tests cover single status rendering, separate Signal clarity, bilingual helper text, mock workflow-preview guidance, zone and unsafe-label absence, Simple Mode ordering, Expert rule basis, conditional and caution wording, deterministic rule-basis output, and existing My Analysis behavior.
