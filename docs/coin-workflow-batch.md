# 코인 기능 통합 정리

기준: main `78d66aa36ba386721b809ce7f14fc26c1143fb13`. 별도 기능 브랜치에서 진행.
main 병합, 기존 웹사이트 배포, Railway 설정 변경, 유료 AI 활성화, 실제 주문은 포함하지 않는다.

## 사용할 수 있는 기능과 위치

| 위치 | 이번 변경 | 확인 방법 |
| --- | --- | --- |
| 상단 검색 | 선택한 거래소의 실제 종목 목록 검색, 한글 주요 코인명 별칭, 로딩·오류·재시도, 주식/예시 출처 구분 | BTC 또는 비트코인 검색 → 마켓 차트. 새로운 상장 종목도 반환 목록에 있으면 검색됨 |
| 종목 분석·내 투자 전체 점검·실시간 조건 검색·자료 도우미 | 큰 체결의 매도 우세와 알트코인 상대 약세 근거를 같은 판단에 반영 | 반대 근거가 있으면 추가 매수 전 확인 안내. 기술적 방향과 가격 기준은 유지 |
| 마켓 설명 패널 | 생성한 예시 시나리오/확률 화면과 AI 분석 예시 제거. 실제 종목 분석 링크, 관련 뉴스, 관심종목 검토, 자료 질문 유지 | 실시간 가격 계획으로 이동. 기존 로컬 AI 자료·비용 확인은 별도 수동 실행으로 유지 |
| 설정 | 실제 화면 수준·언어·시세 모드, 업비트 연결 확인, 뉴스 새로고침, 로컬 AI 설정 확인 | 우측 사용자 버튼 또는 왼쪽 설정. 연결 확인은 사용자가 눌렀을 때 실행 |
| 설정 → 가격 변화 알림 | 사용자 동의를 받은 브라우저 알림. 기존 시나리오의 새 변화 기록에만 발송 | 기본 꺼짐. 권한 거절 시 화면 안 알림 유지. 저장 실패·중복 변화에는 발송하지 않음 |
| 설정 → 매수 계획 계산 | 수량·진입·목표·손절·양쪽 수수료로 필요 금액과 손익 계산 | 손절 < 매수가 < 목표 검증. 실제 주문·보유 기록 생성 없이 계산 |
| 설정 → 과거 데이터로 시험 | 실제 일봉의 단순 20/50일 평균 전략 시험 | 다음 날 시가 체결, 비용·체결 차이 반영, 계속 보유 비교, 일봉 종가 기준 최대 하락 폭·거래 내역 |
| 일일 후보 기록 | 예약 실행처럼 보이던 문구를 조회 시 기록으로 수정, 실제 저장 시각 표시 | 오전 8시 이후 해당 화면을 처음 열 때 생성. 기존 기록·재계산·시장별 분리는 유지 |
| 이전 링크 | /briefing → 뉴스, /discover → 실제 조건 검색, AI 플랜 링크 → 설정 | 실제로 사용할 수 있는 화면으로 연결. 예시 요금·크레딧 화면을 제품 동선에서 제거 |

핵심 메뉴 4개는 그대로 유지한다. 설정·계산·과거 시험에는 별도의 시장 설명 패널을 중복 표시하지 않는다.
기존 포트폴리오·관심종목·거래 기록·목표/손절·백업·저장 시나리오 데이터 형식과 PC 개발환경은 변경하지 않는다.

## 분석 근거의 적용 범위

- 가격 방향은 기존 완료 봉 1H/4H/1D 규칙을 유지한다.
- 체결은 선택 거래소 최근 최대 20건의 상대적으로 큰 거래 표본이다. 지갑 추적이나 큰손 보유량이 아니다.
- 실제 시세·연결·수신 시각이 유효한 표본만 반영한다. 체결 우세의 유효 시간은 마지막 체결 후 60초 이내다.
- BTC 비중의 0.15%p 이상 상승은 BTC 이외 종목의 상대 약세 주의 근거로 사용한다.
  최신 관측은 1시간 이내, 비교 관측 간격은 30분~26시간이다. 비중 상승을 자금 유입이나 BTC 매수 신호로 바꾸지 않는다.
- 반대 근거는 진입 검토를 보류할 수 있지만, 하락·중립·자료 부족을 매수 신호로 바꾸지 않는다.
- 체결/도미넌스가 없으면 해당 근거를 사용하지 않는다. 도미넌스 요청은 공유 캐시를 사용하며 가격 분석을 기다리게 하지 않는다.
- 저장된 검사 결과의 만료 시각에는 시세뿐 아니라 사용한 체결/도미넌스의 유효 시간도 반영한다.
- 요약과 자세한 체결 화면은 같은 표본을 사용한다. 자료 질문의 가격·위험 답변에도 반대 근거를 포함한다.

## 과거 시험의 한계

최근 불러온 최대 300개 일봉 중 완료된 연속 봉 80개 이상이 필요하다. 첫 50개는 준비 기간이다.
누락·중복·잘못된 가격을 임의로 보완하지 않는다. 신호는 전날까지의 종가로 계산하고 다음 날 시가로 거래하며 마지막 보유분은 마지막 종가로 정리한다.
현물 매수/현금만 지원한다. 수수료와 체결 차이를 양쪽 거래에 적용한다.
일봉 중간의 최대 손실, 세금, 거래소 최소 주문, 레버리지·펀딩·청산은 반영하지 않는다.
이 시험은 기존 여러 시간대 종목 분석의 성능 검증이나 미래 수익률이 아니다. 기록은 화면 세션의 계산 결과이며 자동 저장·전략 배포·실제 주문은 없다.

## 아직 외부 연결/별도 개발이 필요한 것

- **공개 사이트의 자유 대화 AI:** AI 서비스 계정·서버 API 키·지출 한도와 사용자 인증/사용량 제한 필요.
  이번에는 설정 안내와 기존 PC용 연결 검사·수동 설명 동선을 제공한다. 자유 대화 AI가 완성되었다고 표시하지 않는다.
  키를 브라우저 저장소/입력창에 저장하지 않는다. AI 요청은 자동으로 실행되지 않는다.
  종목·언어·시세 모드 변경 시 이전 자료와 유료 실행 동의를 초기화한다.
- **앱을 꺼도 오는 알림:** 지속 실행 서버 작업, 사용자별 저장소와 푸시 구독 전달이 필요.
  이번 브라우저 알림도 기존 감시처럼 탭이 보일 때만 작동한다. 최대 3개 감시, 5분 중복 억제, 초기/재접속 시 과거 변화 재현 금지 유지.
  브라우저·운영체제에 따라 시스템 알림이 지원되지 않을 수 있으며 이 경우 화면 안 알림을 사용한다.
- **거래소 계정 자동 동기화/실제 주문/자동매매/클라우드 보유 동기화:** 구현되지 않았다.
  수동 보유 기록과 가격 계획을 이 기능으로 표현하지 않는다.
- **자동 오전 8시 후보 생성:** 서버 예약 작업이 아니다. 화면의 실제 생성 시각을 기준으로 읽어야 한다.

기존 관심종목·뉴스·화면 이동 및 유료 AI 동의 초기화를 테스트한다.
