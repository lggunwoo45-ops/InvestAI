# 간편 분석 → 가격 알림, 빈 후보 검색 개선 — 2026-11-18

## 사용자 흐름과 완료 기준

간편 분석에서 현재 방향·근거·다시 볼 가격을 읽고, 가격 알림을 검토·수정해 저장한다. 회원 서버는 화면을 닫은 뒤에도 같은 거래소·현물/선물·통화의 시세를 확인하고, 가격 통과를 기록한다. 알림 화면에서 최근 서버 확인·감지 기록·발송 상태를 확인하고 종료할 수 있다. 기존 시나리오·선물 검토 기록은 보존한다.

- 간편 화면은 가격 흐름과 판단 요약을 먼저 보여준다. 가격 범위 탭, 전체 전략 조건, 복합 시나리오 저장은 펼쳐서 사용한다. 전문가 화면은 상세 근거·설정을 유지한다.
- 현물 Upbit KRW/BTC/USDT, Binance Spot USDT, 기존 Binance Futures USDT 알림을 거래쌍별로 구분한다. 이전 asset-only 기록은 원래 의미인 Binance 선물 USDT로 읽는다.
- 첫 시세·서버 재시작·수신 공백 이후는 기준점을 다시 잡는다. 그 사이의 가격 통과를 추정하지 않는다. 가격 통과 알림은 거래량·봉 마감·전략 충족이나 주문 체결이 아니다.
- 저장 요청 식별자로 응답 유실 후 재시도 중복을 방지한다. 동일 거래쌍의 새 알림은 기존 감시를 종료하고 기록을 보존한다. 다른 거래소나 통화 알림은 교체하지 않는다.
- 텔레그램은 회원별 연결과 알림별 선택이 필요하다. 미연결 상태에서도 서버 관측 기록은 남는다. API 접수와 휴대폰 수신은 구분한다.

## 후보가 없을 때

매수 조건을 충족하거나 조건 대기 중인 후보가 없으면, 자료가 유효한 종목 중 미충족 조건이 적은 관찰 후보를 최대 3개 보여준다. 매수 추천·상승 확률 순위가 아니며 하락 현물을 숏 신호로 바꾸지 않는다. 거래량·과열·손익비 등 기존 통과 기준을 낮추지 않는다.

자료 부족·시세 만료는 매수 조건 미충족과 따로 표시한다. 12개 검색 도중 먼저 받은 자료가 만료되거나 일시 연결 실패가 발생하면 최대 한 번 실제 자료를 다시 받는다. 동시 조회 2개와 원본 수신 시각에 따른 90초 유효 기간은 유지한다.

## 검증과 운영 경계

자동 검사는 거래쌍·회원 분리, 재시도 중복, 기존 기록 호환, 시작/재시작/공백 후 감지, 텔레그램 payload, 만료 자료 제외, 관찰 후보, 탐색 URL과 계정 변경 중 늦은 응답을 다룬다. 외부 메시지 검사는 모의 전송이다.

별도 로컬 시험 계정으로 실제 BTC/KRW 분석 → 가격 수정·저장 → 알림 화면 이동·새로고침 → 서버 확인 시각 갱신 → 감시 종료 → 종료 기록 보존을 확인했다. 공개 서버에 시험 계정이나 시험 알림을 생성하지 않았다. 실제 시세 후보 검색에서 관찰 후보 3개와 자료 미확인 구분을 확인했다.

휴대폰 실제 수신은 아직 확인하지 않았다. 운영자가 BotFather에서 무료 봇을 만든 뒤 Railway에 `INVESTAI_TELEGRAM_BOT_TOKEN`과 `INVESTAI_TELEGRAM_BOT_NAME`을 직접 입력해야 한다. 토큰은 채팅·저장소·프런트에 기록하지 않는다. 봇 이름은 @ 없이 입력한다. 이후 앱 설정의 개인 텔레그램 연결·테스트 발송과 가격 통과 알림을 실제 단말에서 확인한다. 유료 Telegram 기능이나 새 서버 요금제는 필요하지 않으며 기존 서버 사용량은 적용된다.
