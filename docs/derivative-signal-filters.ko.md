# 과거 파생 지표로 신호 사례 좁히기

2026-10-26: 기존 파생 지표 저장에 이어, 신호 탐색의 과거 사례 비교에 확정 펀딩률과 미결제약정 조건을 연결했다. 추가 유료 자료나 계정 연결은 없다.

## 사용 방법

시장·기록 → 신호 탐색에서 기존 가격 질문이나 신호를 선택한 뒤 추가 조건을 고른다.

- 확정 펀딩: 구분 안 함 / 양수 / 음수. 간편 화면에서는 롱이 숏에게 낸 때 / 숏이 롱에게 낸 때로 설명한다.
- 미결제약정: 구분 안 함 / 정확히 24시간 전보다 증가 / 감소. 단위는 기초자산 수량이다.
- 둘 다 고르면 둘 다 충족해야 한다. 0이나 변화 없음은 양수·음수, 증가·감소에 포함하지 않는다.
- 선택한 조건은 기존 조건 저장·공유 링크에 함께 남고, 간편·전문가 전환에도 유지된다. 과거에 저장한 조건은 추가 조건 없음으로 동작한다.
- 가격 신호 시점 중 당시 자료 확인 가능, 자료 부족으로 제외, 자료는 있지만 조건 불일치, 추가 조건 충족 수를 구분한다. 이 숫자는 중복 제외 전이다. 성과 분포는 이후 관찰까지 완료한 비중복 사례만 사용한다.
- 전문가 관측 사례 표에서 각 사례에 사용한 값과 자료·저장 시각을 확인할 수 있다.

## 시간과 출처

가격과 수익률 가정은 기존 Binance USDⓈ-M 완료 봉을 사용하고, 추가 파생 조건은 Bybit USDT 무기한 선물 자료를 사용한다. 동일 거래소의 자료라고 표시하지 않는다. 신호 조건의 최근 N봉 범위와 별개로, 파생 조건은 최종 신호 봉의 종료 시각에 평가한다.

판정 시각 = `candle.timestamp + timeframe`. `knownAt <= 판정 시각`인 저장 버전만 사용한다. 나중에 수집한 지난주 자료나 나중에 확인된 정정값을 과거 판단에 소급하지 않는다. 봉 종료 시각까지 자료가 없는 경우 제외한다. 따라서 초기 7일 역수집 기록이 있어도 그 7일 전체가 즉시 과거 비교 표본이 되지는 않는다. 실제 저장 시작 이후 시간이 지나고 관찰 기간이 끝나야 표본이 늘어난다.

펀딩은 그 시점에 알고 있던 가장 최근 정산값 중 12시간 이내만 사용한다. OI는 가장 최근 시간별 값 중 2시간 이내이며, 그 값의 정확히 24시간 전 값도 판정 전에 저장돼 있어야 한다. 이전 OI가 0이거나 자료가 없으면 변화율을 계산하지 않는다. 이 12·2시간은 보수적인 사용 유효기간이며 거래소의 정산 주기를 추정하는 값이 아니다. 중간 구간이 모두 연속적이라는 가정을 하지 않고 두 시점의 수량만 비교한다.

서버는 수정 버전을 확인 시각 순으로 적용해 과거 시점별 자료를 만든다. 최신 버전만 내려받아 과거에 대입하지 않는다. `GET /api/research/derivatives/context?asset=BTC&timeframe=1h&from=...&to=...`는 허용 종목·시간봉과 완료 시각 그리드를 검사한다. 최대 10,000시점, 원자료 최대 100,000버전, 분당 30회로 제한한다. 추가 수집이나 주문을 실행하지 않는다.

## 범위와 호환성

파생 조건은 과거 비교와 [자동 신호 감시](derivative-signal-monitor.ko.md)에 적용된다. 감시 등록 시 두 조건과 판단 버전을 고정하며, 미연결 서버는 등록을 거절한다. 조건을 무시한 가격 전용 감시를 조용히 등록하지 않는다. 기존 가격 전용 감시의 엔진 버전·정규화·지문은 유지한다.

`investai-signals-1`의 기존 가격 계산은 유지하고 추가 판단의 버전은 `investai-derivatives-asof-1`로 표시한다. 펀딩 조건을 선택해도 실제 펀딩 비용을 수익률에서 차감하는 것은 아니다. 청산 조건·연간 복합 과열도·독립 표본 장기 검증도 별도 후속 작업이다.

검증: 지연 수집과 정정의 미래 정보 차단, 당시 자료만으로 같은 결과 재현, 24시간 OI 비교·유효기간·0값·누락, 조건 결합과 표본 집계, 조회 범위·출처·시각 검증, 저장·공유·모드 전환 및 오류 시 결과 보류, 기존 감시 호환성을 테스트한다.
