# 투자 검토 흐름 개선

2026-11-11. 범위: 홈 → 간편 분석 → 같은 시장의 가격 기준 저장 → 알림·결과 확인.

## 동작

- 홈에서 새 후보 찾기와 보유 종목 점검을 먼저 선택한다. 저장한 관심종목·가격 기준·과거 감지 기록은 이어보기로 제공한다. 기본 예시 관심종목을 사용자 기록으로 표시하지 않는다.
- 간편 분석은 판단, 이유 두 가지, 다음 확인 조건, 가격 세 가지를 먼저 보여준다. 비용 가정과 세부 근거는 펼쳐서 확인한다. 전문가 계산·차트는 유지한다.
- 분석 가격을 검토·수정한 뒤 기존 시나리오 저장소에 저장한다. 거래소, 종목 ID, 현물 구분, 통화를 유지한다. 잘못 연결된 종목은 대체하지 않고 오류를 표시한다.
- `/review-alerts`에서 기기 가격 알림과 로그인 후 서버 감시 등록을 이어간다. 추천 검증 기록은 별도의 결과 화면으로 연결한다. 가격 관측과 실제 체결, 전략 전체 조건 충족은 구분한다.
- main의 Frontend CI가 성공한 경우에만 그 커밋을 Pages에 게시한다. 게시 직전 main이 바뀌었으면 오래된 버전을 게시하지 않는다.

## 검증

- 자동 검사: Upbit KRW·BTC, Binance 현물 USDT의 저장·이동·통화 보존, 원본 기록 유지, 잘못된 연결, 자료 부족, 잘못된 비용 입력, 최초/재방문 홈, 실시간 갱신 중 요약 카드 중복 방지.
- 로컬 연결 브라우저: 실제 Upbit 데이터로 분석 가격 불러오기 → 감시를 끈 로컬 검증 기록 저장 → 같은 BTC/KRW 알림 → 추천 검증 결과 이동. 공개 계정에는 검증 기록을 만들지 않는다.
- 화면: 390px 분석, 320px 저장·알림, 1366px 전문가 모드 전환. 공개 반영 후 홈·분석·직접 진입 경로를 다시 확인한다.
- 기존 검사는 전체 CI에서 실행한다. 모의 자료를 사용하는 자동 검사와 실제 시세를 보는 화면 검사는 서로 다른 증거다.

## 범위의 한계

- 기기 감시는 화면을 닫으면 멈춘다. 서버 감시는 로그인과 별도 등록이 필요하다.
- 가격 알림은 원래 추천 전략의 모든 거래량·봉 마감 조건을 평가하는 알림이 아니다.
- 이메일·Telegram 발송 설정, 결제, 실제 주문 실행을 추가하거나 활성화하지 않는다.
- 이번 개선은 사용 흐름과 설명·연결을 바꾼다. 전략 수익성을 검증했다고 주장하지 않는다.
