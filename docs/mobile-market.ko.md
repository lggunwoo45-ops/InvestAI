# 모바일 마켓 화면

2026-10-26. 앞선 공통 메뉴 개선만으로는 마켓의 PC용 다중 열과 고정 높이, 자동으로 덮이는 도움말을 해결하지 못했다. 760px 이하에서는 별도 목록·상세 흐름을 사용한다.

- 목록은 검색, 시장·거래소 선택, 관심종목·검토 목록, 정렬을 유지한다. 가격·등락률·거래대금을 카드로 표시하며 20개씩 페이지를 이동해 전체 종목에 접근한다.
- 종목을 누르면 전체 너비의 상세로 이동한다. 목록으로 돌아와도 검색·정렬·관심종목과 목록 페이지를 유지한다. 다른 자산군을 고르면 목록부터 보여준다.
- 상세의 시간봉·차트·분석선 설정·호가·체결은 세로로 배치한다. 차트는 처음에 최근 약 45봉을 보이고 가로 이동과 확대를 지원한다. 세로 터치는 페이지 스크롤에 양보한다. 이력 갱신 때마다 사용자가 고른 확대 범위를 초기화하지 않는다.
- 모바일에서 자동 분석선의 긴 라벨은 분석 모드를 켰을 때 표시한다. 선과 아래 요약은 유지하며, 사용자 추가선은 라벨도 유지한다. 차트 라이브러리의 기본 출처 표시는 유지한다.
- 모바일 도움말은 기본적으로 닫혀 있고 더 보기에서 직접 열고 닫는다. PC의 도움말 열림 설정이 휴대폰 화면 전체를 자동으로 덮지 않는다.
- PC에서도 신호 탐색 안내가 차트 높이를 모두 차지하지 않도록 차트의 최소 높이와 상세 스크롤을 보장한다.

확인 범위는 브라우저의 320·390·430px 폭과 목록→선택→시간봉 변경→목록 복귀 흐름이다. 실제 iOS/Android의 터치·키보드 동작까지 실기기로 검증한 것은 아니다. 다른 모든 페이지의 모바일 최적화가 완료됐다는 의미도 아니다. 시세 연결 실패와 주식 데이터의 기존 제공 범위는 화면 개선과 별개이며 기존 안내를 유지한다.
