# InvestAI 유료 출시 준비 — 2026-11-03

현재 판단: 무료 베타의 고객 경험을 정리하는 단계. 실제 유료 판매 준비 완료로 표시하지 않는다. 사업자·PG 계정이 없다는 운영자의 답변을 전제로 하며, 요금·유료 권한·AI 크레딧은 아직 판매하지 않는다.

## 이번 제품 변경

- 간편 홈에서 BTC 종목 분석으로 바로 진입한다. 실제 가격을 흉내 낸 예시 결과 대신 분석 화면에서 확인할 내용을 설명한다. 기존 조건 검색과 검증 기록은 유지한다.
- `/demo`를 고객용 사용 가이드로 바꾼다. 시작·결과 기록·보유 종목 목적별 동선, 실제 간편/전문가 모드 전환, 지지·저항·무효화 설명, 누락 자료와 계정 복구 안내를 제공한다. `/guide`는 이 화면으로 이동한다.
- `/plans`는 비회원 무료 / 회원 무료 베타 / 아직 판매 전을 구분한다. 서버 기록 한도는 실제 상수를 사용한다. 기존 AI 플랜 북마크도 이 화면으로 이동한다.
- 연결 상태 재확인은 실제 공개 상태 API를 읽는다. 메일·텔레그램 설정을 추정하지 않는다. 실패 시 이전 성공 표시를 걷고 재확인을 안내한다. 설정 연결과 실제 발송 성공은 구분한다.
- 새 경로에 GitHub Pages 직접 진입 파일을 만든다. 안내 화면에서는 보조 분석창을 감춰 본문 공간을 확보한다.

## 바로바라 비교 범위

2026-11-03 공개 홈의 직접 관찰 기준이다. [바로바라](https://barobara.com/)는 무료 텔레그램 체험 → 프리미엄 설정 → 결과 확인을 홈에서 연결하며 브랜드와 핵심 혜택을 명확히 제시한다. InvestAI는 분석·검색·기록을 한 작업 공간에서 다룰 수 있지만 첫 사용 안내와 상품 설명이 약했다. 이번 변경은 이 부분을 보완한다. 문구·도안을 복제하지 않는다.

로그인 후 프리미엄 전체 기능, 실제 알림 도착률, 실제 거래 수익률은 이번 비교로 검증하지 않았다. 과거 벤치마크 문서는 당시 관찰 기록이며 현재 기능 완성률로 인용하지 않는다.

| 구독·권한 | 미구현 | 서버 주문/금액 검증, 중복 결제·웹훅 재전송 방지, 갱신 실패·해지·환불과 권한 회수 통합 테스트 |
| 이메일·외부 알림 | 운영 서버 미설정 | 소유 도메인/발송자 또는 적합한 서비스와 봇 연결 후 검증 계정 수신, 복구·차단·재시도·중복 방지 확인 |

상품 범위를 정할 때 코인과 주식의 데이터 이용 조건 및 유료 투자정보 제공에 적용되는 요건을 별도로 확인한다. [금융위원회 안내](https://www.fsc.go.kr/no010101/82887)를 검토 출발점으로 삼으며, 안내 문구를 붙이는 것만으로 적용 여부가 해결됐다고 간주하지 않는다. 사업 모델에 대한 법적 판단을 이 문서로 확정하지 않는다.

PG는 계정과 계약 조건을 확인한 뒤 선정한다. 예를 들어 [토스페이먼츠 자동결제 문서](https://docs.tosspayments.com/guides/v2/billing)는 추가 계약·심사와 서비스 자체 구독 일정 관리를 설명한다. 결제 버튼 하나만 붙여 구독이 완성됐다고 취급하지 않는다.

## 운영 확인 순서

1. 공개 `/plans/`, `/guide/` 직접 열기·새로고침, 이전 플랜 링크 이동, 간편/전문가 화면, 모바일 가로 넘침을 확인한다.
2. ‘연결 상태 다시 확인’에서 회원 저장·추천 관찰과 이메일·텔레그램의 설정 상태를 구분한다. 상태값만으로 수신 성공을 선언하지 않는다.
3. 기존 무료 베타 가입 한도 50명은 유지한다. 한도 확대나 유료 권한 부여는 관찰 자료와 운영 준비를 확인한 뒤 진행한다.
4. 결제 테스트 환경이 준비되면 성공·실패·중복 요청·갱신·해지·환불·계정 간 권한 격리를 검증하고 실제 판매를 연다.

새 유료 서비스나 계정은 이번 변경에서 신청하지 않는다. 기존 호스팅의 비용과 사용 한도는 계속 적용된다.
