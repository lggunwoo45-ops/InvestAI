# 다음 코인 개발 순서

2026-10-26 사용자 요청: 회원 인증 준비를 먼저 진행하고, 구현되지 않은 코인 기능을 후속 개발한 다음 국내주식·미국주식으로 확장한다. 아래는 개발 우선순위이며 완료나 배포 예약을 의미하지 않는다. 유료 데이터·서버·도메인은 자동 도입하지 않는다.

| 1 | 알림 실제 운영 연결 | 계정별 서버 감시와 Telegram 연결 코드 구현. 운영 봇·실제 수신 미확인 | 사용자 지정 시험 채널로 연결·수신·중복 방지·연결 해제·서버 재시작 확인 |

1은 신규 분석 화면보다 운영 설정과 실제 전달 검증이 중심이다. 2026-10-26 사용자 요청에 따라 2를 검토하고 무료 공급 조건을 확정하지 못해 3의 저장·조회와 [과거 신호 조건 결합](derivative-signal-filters.ko.md)을 구현했다. 제공 범위와 ETF 검토 근거는 [파생 지표 기록실](derivatives-history.ko.md)을 따른다. [파생 조건 자동 감시](derivative-signal-monitor.ko.md)까지 연결했다. [기간별 과열 참고 지표와 모바일 개선](relative-heat-mobile.ko.md)과 [비용·별도 구간 검증](signal-cost-validation.ko.md)을 구현했다. 다음 검증 보강은 조건을 미리 고정한 이후의 새 기록 비교와 같은 거래소의 실제 펀딩 비용 연결이다.

경제 일정과 Bybit 청산 관측은 [현재 제공 범위](market-events.ko.md), 회원 인증 준비는 [메일 기능 문서](member-email.ko.md)를 따른다. 이메일 인증 발송은 별도 설정 대기이며, 유료 구독 결제는 계속 후순위다.

주식 확장은 국내주식 실제 시세·차트·공시 연결부터 시작한다. 현재 주식 종목 카탈로그의 모의 시세를 실제 시세로 대체하고, 거래시간·휴장·통화·수정주가·데이터 제공 권한을 확인한다. 이후 미국주식으로 확장한다. 코인의 파생상품 위험 계산을 주식 현물에 그대로 적용하지 않는다.
