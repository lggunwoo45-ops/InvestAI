# 간편·전문가 화면 구분

## 문제와 적용 범위

코인 분석에서 두 표시 모드는 거의 같은 화면을 사용했다. 주요 기능은 연결되어 있었지만, 새 사용자가 현재 판단과 확인할 가격을 찾기 어려웠다. 이번 변경은 기존 분석 엔진을 유지하면서 정보의 우선순위와 화면 구성을 구분한다.

- 간편모드는 홈 / 종목 분석 / 내 투자 / 종목 찾기를 상단에 둔다. 마켓·뉴스·데모·설정·언어·전체 검색은 ‘더 보기’에서 접근한다. Ctrl/Cmd+K로 메뉴를 열고 검색에 초점을 옮기며 Escape로 닫는다.
- 전문가모드는 기존 사이드바와 작업 도구를 유지한다. 모드 선택 글자를 읽기 쉽게 확대한다.
- 코인 간편 분석은 실제 엔진의 행동 안내 한 문장, 짧은 이유, 관심/주의/상승 검토 가격을 먼저 보여준다. 자세한 이유는 펼쳐 볼 수 있다. 가격 계획이 없으면 숫자를 만들어 표시하지 않는다.
- 전문가 분석에는 검증된 완료 봉의 종가 차트와 1시간·4시간·일봉 지표 비교를 기본으로 표시한다. 차트는 기존 엔진이 검증한 최근 최대 60개 완료 봉을 사용한다. 진행 중 봉과 현재가를 과거 종가로 섞지 않으며, 시세가 오래되거나 자료가 무효해지면 해당 차트를 철회한다.
- 두 모드는 동일한 CryptoDecisionPanel과 계산 결과를 사용한다. 새 차트는 별도 시세 구독이나 API 요청을 만들지 않는다.
- 평단가와 수량이 있고 유효한 현재 분석 가격이 있으면 평가손익을 함께 표시한다. 수량이 없으면 손익 금액을 추정하지 않는다.
- 연결 중 준비율·경과 시간·지연 안내는 유지한다. 정상 준비 완료 표시는 짧게 줄인다. 데이터 부족을 매매 대기 판단으로 바꾸지 않는다.
- 상세 근거, 큰 체결·도미넌스, 시나리오 저장, 평단가·메모, 분석 질문 기능은 기존 탭에서 계속 접근한다. 분석 질문은 상세 근거로 모아 요약 화면의 별도 카드를 줄였다.
- 종목·선택 탭·입력 중 평단가·메모·시나리오 초안을 유지한다. 저장 형식, PC 개발 명령, 서버와 API 설정은 변경하지 않는다.

## 확인 기준

- 같은 자료에서 모드를 바꿔도 결론과 가격 계획이 같다.
- 간편 화면에는 전문가 차트/지표 표가 나타나지 않고, 전문가 화면에는 유효한 자료로 표시된다.
- 모드 전환 후 개인 입력과 선택 탭이 유지되며, 평단가를 입력하는 것만으로 보유 기록을 만들지 않는다.
- 기존 준비율, 자료 부족, 모의 데이터, 지연·재연결, 오래된 시세 제외 검사를 유지한다.
- 네 핵심 메뉴와 추가 메뉴에서 기존 페이지로 이동할 수 있다. 메뉴 키보드 닫기와 전체 검색 단축키를 확인한다.
- 실제 업비트 BTC로 간편·전문가 전환 및 차트를 확인하고 390px 화면의 가로 넘침과 메뉴 접근을 점검한다.

## 제한사항과 다음 단계

검증 결과: 전체 176개 테스트 파일의 927개 테스트, 타입 검사, `/InvestAI/` 경로의 배포 빌드 통과. 린트 오류는 없으며 기존 경고 3개가 남아 있다. 실제 업비트 BTC의 3/3 시간대 분석과 전문가 차트, 모드 전환 시 평단가·메모 유지, 설정 메뉴 이동과 분석 복귀를 확인했다. 390px에서 문서 너비 390/390, 본문 너비 382/382로 가로 넘침이 없었다. 시험 입력은 정리했고 실제 보유 내역은 변경하지 않았다.

분석 알고리즘과 정확도, 예측 성능을 개선한 변경은 아니다. 전문가 차트는 완료 봉 종가의 개요이며 마켓의 기존 캔들 차트·차트 도구를 대체하지 않는다. 상세 가격은 기존 통화와 정밀도를 유지한다. 주식 상세 분석 구성은 기존 기능을 유지하며 이번 코인 화면 개편과 동일한 수준으로 재설계하지 않았다.

계정 동기화, 유료 AI 연결, 사용자별 API 할당량, 서버 비용 상한은 추가하지 않았다. 다음 단계에서 과도한 사용 보호와 실제 사용자 피드백을 먼저 검토한다. 이번 PR은 별도 브랜치에서 검토하며 사용자 승인 전 main 병합·배포하지 않는다.
