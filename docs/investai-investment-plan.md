# 내 투자 강화 — 손익 요약과 개인 투자 기준

기준: PR #80 병합 후 main `b4c77eb`. 별도 브랜치 `feat/portfolio-investment-plan`에서 개발하며 사용자 검토 후 병합한다.

## 동작

- 기준통화별 보유 기록 수, 조회 가능한 기록 수, 매입금액, 평가금액, 평가손익, 수익률을 표시한다. 서로 다른 통화는 환산하거나 합치지 않는다.
- 합산 수익률은 전체 평가손익 / 전체 매입금액 × 100이다. 개별 수익률의 단순 평균을 사용하지 않는다.
- 한 통화에서 일부 기록의 시세가 없으면 매입금액과 조회 범위만 표시하고 전체 평가금액·손익·수익률은 보류한다. 숫자 합산이 유한한 범위를 벗어나도 합계를 표시하지 않는다.
- 목표가와 손절 기준가는 선택 입력이다. 직접 정한 가격만 저장하며 추천 가격을 자동 생성하지 않는다. 가격은 기준통화 단위의 유한한 양수이며, 둘 다 설정하면 손절 기준가 < 목표가를 만족해야 한다. 평단가보다 높은 손절 기준도 허용한다.
- 현재가가 목표가 이상 또는 손절 기준가 이하일 때 화면에 ‘기준 도달’을 표시한다. 이는 조회 시점의 비교이며 과거 도달 이력이나 지속 모니터링이 아니다. 시세가 없으면 판정을 보류한다. 모의 시세는 모의라고 표시한다.
- 각 기준의 현재가 대비 변동률과 해당 가격에서의 평가손익을 표시한다. 본전 회복에 필요한 상승률은 (평단가 / 현재가 − 1) × 100이다. 예: 20% 손실 상태의 회복 상승률은 25%.
- 보유 내역이 있으면 등록 폼은 접어두고 ‘코인 추가’ 또는 ‘수정’으로 연다. 수정 후 기록 순서를 유지한다.
- 종목 분석 링크는 보유 기록 ID와 종목 ID만 전달한다. 저장 평단가·수량·투자 기준을 로컬에서 읽어 별도 카드로 표시한다. 분석의 임시 평단가 변경은 저장한 계획을 바꾸지 않는다. 다른 종목을 고르면 저장 계획이 사라지고, 다른 탭에서 해당 기록을 삭제해도 카드가 사라진다.

## 저장 호환성

기존 `investai.portfolio.v1`의 선택 속성 `targetPrice`, `stopPrice`로 확장한다. 기존 기록은 변경 없이 읽으며 명시적 저장 전에 마이그레이션이나 덮어쓰기를 하지 않는다. 빈 입력으로 기준을 해제할 수 있다. 잘못된 저장 형식, 미지원 버전, 쓰기 제한, 원본 충돌 시 기존 원본을 보존하는 정책을 유지한다. 관심종목과 저장 공간을 분리한다.

## 검증 기준

| 기준 | 자동 검증 |
| --- | --- |
| 기존 데이터 읽기, 기준 추가/수정/해제 | 저장소 호환성 및 화면 워크플로 테스트 |
| 잘못된 가격/순서, 오버플로, 손상 데이터 보존 | 저장소 검증 테스트 |
| 통화 분리, 가중 합산 수익률, 부분 시세 보류 | portfolioReview 계산 테스트 |
| 목표·손절 경계값, 본전 회복률, 시세 없음 | portfolioReview 계산 및 화면 테스트 |
| 분석 연결, 임시 입력 격리, 다른 종목/삭제 시 제거 | MyAnalysisPage 통합 테스트 |
| 다른 탭 변경 시 이전 편집 취소 | PortfolioPage 통합 테스트 |

## 제한

검증 결과: 린트·타입 검사·140개 파일의 706개 테스트·프로덕션 빌드 통과. 기존 린트 경고 3개와 500kB 초과 번들 경고는 유지된다. 브라우저에서 가상 보유 기록으로 수정/저장, 저장한 기준의 종목 분석 전달, 390px 모바일 요약·계획 카드와 가로 넘침 없음을 확인했다. 테스트 데이터는 분리된 로컬 주소에서만 사용했다.

현물 수동 보유 기록과 미실현 손익을 다룬다. 자동 주문, 푸시 알림, 백그라운드 감시, 실현손익, 수수료·세금·환율, 거래소 계좌 연결은 포함하지 않는다. 로컬 저장은 암호화·클라우드 백업·기기 동기화를 제공하지 않으며, localStorage의 극히 동시적인 다중 탭 쓰기를 원자적으로 직렬화하지 않는다. JavaScript 부동소수점 계산을 사용한다. 다크모드는 별도 후속 범위다.
